# @kashi-ui/css

استایل همهٔ کامپوننت‌های [کاشی](https://github.com/Sepantapouya/Kashi) با CSS خالص؛ برای React، Vue، Svelte، Angular یا HTML ساده.

```bash
npm i @kashi-ui/css
```

```js
import "@kashi-ui/css";
```

یا از CDN:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@kashi-ui/css/dist/kashi.css">

<html lang="fa" dir="rtl">
<button class="k-btn k-btn--primary">ثبت‌نام</button>
```

- راست‌به‌چپ از پایه با Logical Properties
- تم تیره (پیش‌فرض) و روشن با `data-theme="light"`
- همهٔ استایل‌ها در Cascade Layer؛ CSS شما همیشه اولویت دارد
- فونت متغیر وزیرمتن همراه پکیج (لایسنس SIL OFL 1.1، اثر صابر راستی‌کردار)
