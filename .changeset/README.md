# Changesets

هر تغییری که باید در نسخهٔ بعدی منتشر شود، یک فایل changeset لازم دارد:

```bash
npx changeset
```

نوع تغییر را انتخاب کنید (patch برای رفع باگ، minor برای قابلیت جدید، major برای تغییر ناسازگار) و یک خط توضیح بنویسید. هر سه پکیج کاشی همیشه با یک نسخه منتشر می‌شوند.

پس از ادغام در `main`، گردش کار Release یک Pull Request با نسخه‌های جدید و CHANGELOG می‌سازد. با ادغام آن PR، پکیج‌ها روی npm منتشر می‌شوند.
