آیکون‌ها برای Vue و Svelte: `@kashi-ui/icons/vue` با یک کامپوننت برای هر آیکون (`IconSearch`، …) و `<Icon name>`، و `@kashi-ui/icons/svelte` با `Icon.svelte` و دادهٔ هر آیکون (`iconSearch`، …). مثل React فقط آیکون‌های استفاده‌شده در باندل می‌مانند. Vue و Svelte وابستگی اختیاری‌اند.
