حالت تاریک دیگر یک امکان لوکس نیست؛ بسیاری از کاربران سیستم‌عاملشان را تیره گذاشته‌اند و سایتی که با یک صفحهٔ کاملاً سفید باز می‌شود، چشمشان را می‌زند. ولی تم تیرهٔ خوب با `filter: invert(1)` یا برعکس کردن رنگ‌ها ساخته نمی‌شود. اگر پایه‌اش درست باشد، اضافه کردنش ساده است.

## پایه: توکن‌های معنایی

اگر در CSS رنگ‌ها را مستقیم نوشته باشید (`background: #fff; color: #111`)، برای تم تیره باید تک‌تک‌شان را پیدا و بازنویسی کنید. اگر از [توکن‌های معنایی](/articles/design-tokens-guide/) استفاده کرده باشید، تم تیره فقط یک بلوک CSS است:

```css
[data-theme="light"] {
  --k-bg-primary: #ffffff;
  --k-text-primary: #101418;
  --k-border-secondary: #e4e7eb;
}
[data-theme="dark"] {
  --k-bg-primary: #0a0c0f;
  --k-text-primary: #f2f4f5;
  --k-border-secondary: #23282e;
}
.card { background: var(--k-bg-primary); color: var(--k-text-primary); }
```

کامپوننت‌ها هیچ‌چیز از تم نمی‌دانند؛ فقط نقش‌ها را صدا می‌زنند.

## تیره یعنی برعکس نیست

تم تیره قاعده‌های خودش را دارد:

- **سیاه مطلق نه.** `#000` روی صفحه‌های OLED لبه‌های تند می‌سازد و متن سفید رویش «می‌لرزد». خاکستری بسیار تیره (مثل `#0a0c0f`) چشم‌نوازتر است.
- **سفید مطلق نه.** متن اصلی را کمی کم‌نورتر از سفید بگذارید؛ کنتراست کافی می‌ماند و خیرگی کم می‌شود.
- **عمق با روشن‌تر شدن، نه سایه.** در تم روشن، کارت بالاتر سایهٔ بیشتری دارد. در تم تیره سایه دیده نمی‌شود؛ لایه‌های بالاتر کمی روشن‌ترند.
- **رنگ برند را دوباره تنظیم کنید.** رنگی که روی سفید خوب است، روی زمینهٔ تیره ممکن است کدر یا خیلی تند باشد. معمولاً یک پلهٔ روشن‌تر از همان طیف بهتر است.
- **رنگ‌های وضعیت روشن‌تر.** قرمز خطا و سبز موفقیت در تم تیره باید روشن‌تر باشند تا کنتراست ۴٫۵ به ۱ را حفظ کنند.

## احترام به تنظیم سیستم

پیش‌فرض خوب این است که سایت از تنظیم سیستم‌عامل پیروی کند و کاربر بتواند آن را عوض کند:

```js
const saved = localStorage.getItem("theme"); // "light" | "dark" | null
const system = matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
document.documentElement.dataset.theme = saved ?? system;
```

و ویژگی `color-scheme` را هم بگذارید تا نوار اسکرول، فیلدهای فرم پیش‌فرض و پس‌زمینهٔ صفحه هم تیره شوند:

```html
<meta name="color-scheme" content="dark light">
```

## جلوگیری از چشمک

اگر تم بعد از بارگذاری جاوااسکریپت اعمال شود، صفحه یک لحظه سفید و بعد تیره می‌شود. راه حل: اسکریپت کوچک تعیین تم را **درون `<head>` و پیش از CSS اصلی** بگذارید، به‌شکل inline و بدون `defer`. چند خط کد است و پیش از اولین نقاشی صفحه اجرا می‌شود.

## تصویرها و نمودارها

<Figure n={3} alt="نمودار میله‌ای یکسان در تم روشن و تیره که رنگ میله‌ها و پس‌زمینه‌اش از توکن‌ها می‌آید" caption="وقتی رنگ نمودار هم از توکن بیاید، با عوض شدن تم خودش هماهنگ می‌شود." />

- **لوگو و تصویرهای با پس‌زمینهٔ سفید** در تم تیره مثل یک مستطیل نورانی دیده می‌شوند. از SVG با `currentColor` یا نسخهٔ تیرهٔ جداگانه استفاده کنید (`<picture>` با `media="(prefers-color-scheme: dark)"`).
- **رنگ‌های نمودار** را هم از توکن بگیرید تا در تم تیره روشن‌تر شوند.
- **عکس‌ها را تیره نکنید.** فیلتر روی عکس محصول، رنگ واقعی را خراب می‌کند.

## بخشی تیره در صفحهٔ روشن

گاهی یک بخش (مثل هیروی صفحهٔ اصلی یا پانویس) همیشه تیره است. با توکن‌ها این هم ساده است: `data-theme="dark"` را روی همان بخش بگذارید و همهٔ کامپوننت‌های داخلش خودشان تیره می‌شوند.

```html
<section data-theme="dark">…</section>
```

## جمع‌بندی

تم تیرهٔ خوب نتیجهٔ توکن‌های معنایی است، نه برعکس کردن رنگ‌ها. سیاه و سفید مطلق را کنار بگذارید، رنگ برند و وضعیت‌ها را برای زمینهٔ تیره تنظیم کنید، از تنظیم سیستم پیروی کنید و جلوی چشمک را بگیرید. همهٔ کامپوننت‌های کاشی با `data-theme` در هر دو تم کار می‌کنند و [تم‌ساز](/docs/theming/) مقدارهای تیره را برای رنگ برند شما هم می‌سازد.
