کد ملی در فرم‌های ایرانی همه‌جا هست: ثبت‌نام، احراز هویت، خرید بلیت و فاکتور. خوشبختانه کد ملی یک رقم کنترل دارد و می‌شود بدون تماس با هیچ سروری فهمید که آیا عددِ واردشده اصلاً می‌تواند کد ملی باشد یا نه. این کار جلوی بیشتر اشتباه‌های تایپی را همان لحظه می‌گیرد.

یک نکته را از اول روشن کنیم: رقم کنترل فقط می‌گوید عدد «ساختار درستی» دارد. اینکه این کد واقعاً به کسی تعلق دارد یا به همین کاربر، فقط با استعلام از مرجع رسمی معلوم می‌شود.

## ساختار کد ملی

کد ملی ده رقم دارد. نه رقم اول شناسه است و رقم دهم «رقم کنترل» که از نه رقم قبلی حساب می‌شود.

## الگوریتم رقم کنترل

1. نه رقم اول را به ترتیب در ۱۰، ۹، ۸ … تا ۲ ضرب کنید و حاصل‌ها را جمع بزنید.
2. باقی‌ماندهٔ جمع بر ۱۱ را حساب کنید؛ اسمش را `r` بگذاریم.
3. اگر `r` کمتر از ۲ بود، رقم کنترل باید خود `r` باشد؛ وگرنه باید `11 - r` باشد.

یک مثال ساختگی: برای `1234567891`، جمع حاصل‌ضرب‌ها ۲۱۰ است. باقی‌ماندهٔ ۲۱۰ بر ۱۱ می‌شود ۱، که کمتر از ۲ است؛ پس رقم کنترل باید ۱ باشد، و هست.

```js
function isValidNationalId(input) {
  const id = toEnglishDigits(input).replace(/\D/g, "");
  if (!/^\d{10}$/.test(id)) return false;
  if (/^(\d)\1{9}$/.test(id)) return false; // ۱۱۱۱۱۱۱۱۱۱ و مانند آن
  let sum = 0;
  for (let i = 0; i < 9; i++) sum += Number(id[i]) * (10 - i);
  const r = sum % 11;
  const check = Number(id[9]);
  return r < 2 ? check === r : check === 11 - r;
}
```

چرا خط مربوط به ارقام تکراری؟ کدهایی مثل `1111111111` از نظر ریاضی رقم کنترل درستی دارند، ولی صادر نمی‌شوند و بیشتر وقت‌ها کاربر برای رد شدن از فرم آن‌ها را تایپ می‌کند.

## سه خطای رایج

### ۱. رد کردن ارقام فارسی

بیشتر کاربران ایرانی با صفحه‌کلید فارسی تایپ می‌کنند و «۰۰۱۲۳…» می‌نویسند. اگر اعتبارسنجی فقط `[0-9]` را بپذیرد، کد درست را رد می‌کند. همیشه پیش از بررسی، ارقام فارسی و عربی را به انگلیسی تبدیل کنید. روش تبدیل را در [مقالهٔ ارقام فارسی در جاوااسکریپت](/articles/persian-digits-javascript/) گفته‌ایم.

### ۲. از دست رفتن صفر اول

خیلی از کدهای ملی با صفر شروع می‌شوند. اگر فیلد را `type="number"` بگذارید یا مقدار را در پایگاه داده به‌شکل عدد ذخیره کنید، صفر اول حذف می‌شود و کد نه‌رقمی و نامعتبر می‌شود. کد ملی **متن** است، نه عدد:

```html
<input inputmode="numeric" autocomplete="off" maxlength="10">
```

`inputmode="numeric"` صفحه‌کلید عددی گوشی را باز می‌کند بدون اینکه مقدار به عدد تبدیل شود.

### ۳. خطای زودهنگام

نشان دادن «کد ملی نامعتبر است» وقتی کاربر هنوز رقم سوم را تایپ می‌کند، آزاردهنده است. خطا را وقتی نشان دهید که کاربر از فیلد بیرون رفت یا ده رقم کامل شد.

## یک فیلد کد ملی خوب

<Figure n={3} alt="فیلد کد ملی در سه حالت: خالی با راهنما، معتبر با تیک سبز و نامعتبر با پیام خطای روشن" caption="راهنمای کوتاه پیش از تایپ، و پیام خطایی که می‌گوید چه کار کنیم، نه فقط اینکه اشتباه شده." />

- **برچسب روشن:** «کد ملی»، نه «شناسه» یا «کد».
- **راهنما:** «۱۰ رقم، بدون خط تیره».
- **پذیرش هر نوع رقم** و حذف خودکار فاصله و خط تیره.
- **پیام خطای مفید:** «کد ملی باید ۱۰ رقم باشد» یا «این کد ملی معتبر نیست؛ رقم‌ها را دوباره بررسی کنید». برای لحن پیام خطا [این مقاله](/articles/persian-error-messages/) را ببینید.
- **اعتبارسنجی در سرور هم.** بررسی سمت مرورگر برای راحتی کاربر است؛ سرور نباید به آن اعتماد کند.

## راه کوتاه: تابع و کامپوننت آماده

تابع بالا با همهٔ این نکته‌ها در `@kashi-ui/persian` هست و ارقام فارسی، فاصله و خط تیره را خودش می‌پذیرد:

```js
import { isValidNationalId } from "@kashi-ui/persian";

isValidNationalId("۱۲۳۴۵۶۷۸۹۱"); // true
isValidNationalId("1111111111"); // false
```

و اگر فیلد آماده می‌خواهید، کامپوننت کد ملی کاشی هم تبدیل رقم و پیام خطا را دارد و هم در React و هم به‌شکل وب کامپوننت در دسترس است:

```tsx
import { PersianInput } from "@kashi-ui/react";

<PersianInput kind="national-id" label="کد ملی" name="national_id" required />
```

```html
<kashi-national-id name="national_id" required></kashi-national-id>
```

برای شناسهٔ ملی شرکت‌ها (یازده رقمی) هم `kind="legal-id"` هست. همهٔ فیلدهای ایرانی را در [صفحهٔ ورودی‌های فارسی](/docs/persian/input/) ببینید.

## جمع‌بندی

رقم کنترل کد ملی را می‌شود با چند خط کد بررسی کرد. مهم‌تر از خود الگوریتم، رعایت جزئیات است: ارقام فارسی را بپذیرید، کد ملی را متن نگه دارید، خطا را به‌موقع و با پیام روشن نشان دهید و بررسی را در سرور هم تکرار کنید.
