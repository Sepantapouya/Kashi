در فرم برداشت وجه، ثبت حساب فروشنده یا بازگشت پول، یک رقم اشتباه در شماره کارت یا شبا یعنی پولی که به حساب دیگری می‌رود یا تراکنشی که برمی‌گردد. هر دو شماره رقم کنترل دارند و می‌شود بیشتر اشتباه‌های تایپی را همان لحظه در مرورگر گرفت.

مثل [کد ملی](/articles/national-id-validation/)، این بررسی فقط می‌گوید شماره «ساختار درستی» دارد؛ اینکه حساب وجود دارد و به چه کسی تعلق دارد، فقط با استعلام از بانک یا درگاه معلوم می‌شود.

## شماره کارت: ۱۶ رقم و الگوریتم لون

کارت‌های بانکی ایرانی ۱۶ رقمی‌اند. شش رقم اول (BIN) بانک صادرکننده را مشخص می‌کند و رقم آخر رقم کنترل است که با **الگوریتم لون** (Luhn) حساب می‌شود؛ همان الگوریتمی که کارت‌های بین‌المللی هم استفاده می‌کنند.

<Figure n={1} alt="شانزده رقم کارت که رقم‌های جایگاه فرد دو برابر شده‌اند و جمع نهایی بر ۱۰ بخش‌پذیر است" caption="در الگوریتم لون، یکی در میان رقم‌ها دو برابر می‌شوند؛ کارت معتبر است اگر جمع نهایی بر ۱۰ بخش‌پذیر باشد." />

قدم‌ها برای کارت ۱۶ رقمی:

1. از رقم اول (سمت چپ)، رقم‌های جایگاه فرد (اول، سوم، پنجم …) را دو برابر کنید.
2. اگر حاصل بیشتر از ۹ شد، ۹ را از آن کم کنید.
3. همهٔ رقم‌ها را، دوبرابرشده‌ها و بقیه، جمع بزنید.
4. اگر جمع بر ۱۰ بخش‌پذیر بود، شماره معتبر است.

```js
function isValidCard(input) {
  const n = toEnDigits(input).replace(/\D/g, "");
  if (!/^\d{16}$/.test(n)) return false;
  let sum = 0;
  for (let i = 0; i < 16; i++) {
    let d = Number(n[i]);
    if (i % 2 === 0) { d *= 2; if (d > 9) d -= 9; }
    sum += d;
  }
  return sum % 10 === 0;
}
```

## نام بانک از شش رقم اول

شش رقم اول هر کارت به یک بانک تعلق دارد؛ مثلاً `603799` بانک ملی است. نمایش نام و لوگوی بانک کنار فیلد، یک تأیید ضمنی قوی است: اگر کاربر کارت ملت دارد و «بانک ملی» می‌بیند، خودش اشتباه را پیدا می‌کند.

```js
import { getBankByCard, isValidCardNumber } from "@kashi-ui/persian";

getBankByCard("6037 9912 3456 7893")?.name; // «بانک ملی»
isValidCardNumber("6037991234567893");      // true
```

## شبا: IR و ۲۴ رقم، با mod 97

شمارهٔ شبا (IBAN ایران) ۲۶ نویسه دارد: «IR»، دو رقم کنترل و ۲۲ رقم شمارهٔ حساب که سه رقمش (پس از رقم‌های کنترل) شناسهٔ بانک است. اعتبارسنجی آن طبق استاندارد بین‌المللی IBAN (ISO 13616) با باقی‌ماندهٔ تقسیم بر ۹۷ انجام می‌شود.

<Figure n={2} alt="شمارهٔ شبا تقسیم‌شده به بخش‌ها: IR، رقم‌های کنترل، شناسهٔ بانک و شمارهٔ حساب، با نمودار جابه‌جایی برای محاسبهٔ mod 97" caption="برای بررسی، چهار نویسهٔ اول به انتها منتقل و حرف‌ها به عدد تبدیل می‌شوند؛ باقی‌ماندهٔ تقسیم بر ۹۷ باید ۱ باشد." />

قدم‌ها:

1. فاصله‌ها را حذف کنید و ارقام فارسی را انگلیسی کنید.
2. چهار نویسهٔ اول («IR» و دو رقم کنترل) را به انتهای رشته ببرید.
3. حرف‌ها را به عدد تبدیل کنید: I = ۱۸ و R = ۲۷.
4. باقی‌ماندهٔ تقسیم این عدد بزرگ بر ۹۷ را حساب کنید. اگر ۱ بود، شبا معتبر است.

عدد حاصل بیش از ۲۵ رقم دارد و از دقت `Number` در جاوااسکریپت بیرون است. یا از `BigInt` استفاده کنید یا باقی‌مانده را تکه‌تکه حساب کنید:

```js
function mod97(digits) {
  let r = 0;
  for (const ch of digits) r = (r * 10 + Number(ch)) % 97;
  return r;
}

function isValidIban(input) {
  const s = toEnDigits(input).toUpperCase().replace(/[\s-]/g, "");
  const d = s.startsWith("IR") ? s.slice(2) : s;
  if (!/^\d{24}$/.test(d)) return false;
  return mod97(d.slice(2) + "1827" + d.slice(0, 2)) === 1;
}
```

## طراحی فیلدهای کارت و شبا

<Figure n={3} alt="فیلد کارت و فیلد شبا در حالت معتبر با نام بانک و در حالت نامعتبر با پیام خطای روشن" caption="گروه‌بندی چهاررقمی، نام بانک و پیام خطایی که می‌گوید کدام بخش را بررسی کنیم." />

- **`dir="ltr"`** روی خود فیلد تا گروه‌های رقم برعکس دیده نشوند؛ برچسب و خطا فارسی بمانند.
- **گروه‌های چهاررقمی** هنگام تایپ؛ اشتباه را راحت‌تر پیدا می‌کنید.
- **پیشوند ثابت IR** برای شبا؛ کاربر فقط ۲۴ رقم وارد کند و اگر IR را هم چسباند، خودتان حذفش کنید.
- **چسباندن آزاد:** کاربران شبا را از اپ بانک کپی می‌کنند، با فاصله یا خط تیره.
- **`autocomplete="cc-number"`** برای کارت تا مرورگر بتواند شمارهٔ ذخیره‌شده را پیشنهاد کند؛ برای شبا `autocomplete="off"`.
- **پیام خطای دقیق:** «شمارهٔ کارت ۱۶ رقم است» یا «این شماره شبا معتبر نیست؛ رقم‌ها را با اپ بانک مقایسه کنید».

یک نکتهٔ امنیتی: شمارهٔ کارت کامل را در لاگ‌ها، آنالیتیکس یا نشانی صفحه نگذارید. برای نمایش، فقط چهار رقم آخر کافی است.

## جمع‌بندی

شماره کارت با الگوریتم لون و شبا با mod 97 در مرورگر قابل‌بررسی‌اند و بیشتر اشتباه‌های تایپی را می‌گیرند. نام بانک را نشان دهید، فیلد را چپ‌به‌راست کنید، چسباندن را آزاد بگذارید و بررسی را در سرور هم تکرار کنید. برای بقیهٔ فیلدهای ایرانی، [مقالهٔ طراحی فرم فارسی](/articles/persian-form-design/) را ببینید.
