Tailwind CSS محبوب‌ترین روش استایل‌دهی در پروژه‌های تازهٔ React و Next.js است، ولی بیشتر نمونه‌کدهایش برای انگلیسی نوشته شده: `ml-4`، `pr-2`، `text-left`. اگر همین‌ها را در پروژهٔ فارسی کپی کنید، همان مشکل‌های قدیمی راست‌چین برمی‌گردد. خوشبختانه Tailwind ابزار درست را دارد.

## قدم اول: جهت در HTML

مثل هر سایت فارسی دیگری، جهت و زبان روی `html` تعیین می‌شود، نه با کلاس:

```html
<html lang="fa" dir="rtl">
```

Tailwind خودش از این `dir` پیروی می‌کند؛ کلاس‌های منطقی و متغیرهای `rtl:` و `ltr:` همه بر اساس آن کار می‌کنند.

## کلاس‌های منطقی به‌جای چپ و راست

Tailwind برای هر کلاس فیزیکی، معادل منطقی دارد. «s» یعنی start (ابتدای خط، در فارسی راست) و «e» یعنی end:

<Figure n={1} alt="جدول تبدیل کلاس‌های فیزیکی Tailwind مثل ml-4 و pr-2 به کلاس‌های منطقی ms-4 و pe-2" caption="با کلاس‌های منطقی، یک کد هم در فارسی و هم در انگلیسی درست است." />

| فیزیکی (نکنید) | منطقی (بکنید) |
| --- | --- |
| `ml-4` / `mr-4` | `ms-4` / `me-4` |
| `pl-2` / `pr-2` | `ps-2` / `pe-2` |
| `left-0` / `right-0` | `start-0` / `end-0` |
| `text-left` / `text-right` | `text-start` / `text-end` |
| `rounded-l-lg` | `rounded-s-lg` |
| `border-r` | `border-e` |

```html
<div class="flex items-center gap-3">
  <img class="size-10 rounded-full" src="…" alt="">
  <div class="text-start">
    <p class="font-bold">سارا محمدی</p>
    <p class="text-sm text-gray-500">طراح محصول</p>
  </div>
  <span class="ms-auto">…</span>
</div>
```

`ms-auto` آخرین عنصر را به انتهای ردیف (در فارسی، سمت چپ) می‌برد. برای فاصلهٔ بین آیتم‌ها هم `gap` بهترین انتخاب است؛ به جهت کاری ندارد.

## متغیرهای rtl و ltr

برای جاهایی که واقعاً باید رفتار متفاوت باشد، Tailwind متغیرهای `rtl:` و `ltr:` دارد. مهم‌ترین کاربردش، قرینه کردن آیکون‌های جهت‌دار است:

```html
<svg class="size-5 rtl:-scale-x-100"><!-- فلش «بعدی» --></svg>
```

ولی از این متغیرها کم استفاده کنید. اگر برای هر عنصر `rtl:` می‌نویسید، احتمالاً جایی کلاس فیزیکی مانده که باید منطقی شود. دربارهٔ اینکه کدام آیکون‌ها قرینه شوند، [مقالهٔ آیکون‌های راست‌به‌چپ](/articles/rtl-icons-direction/) را ببینید.

## فونت و ارقام

فونت فارسی را در تم Tailwind تعریف کنید تا `font-sans` همان باشد:

```css
@import "tailwindcss";

@theme {
  --font-sans: "Vazirmatn", Tahoma, system-ui, sans-serif;
}
```

دو نکتهٔ دیگر:

- **`tracking-*` را روی متن فارسی نگذارید.** فاصلهٔ بین حروف، اتصال حروف فارسی را خراب می‌کند.
- **`tabular-nums` برای جدول‌ها و قیمت‌ها** مفید است، ولی روی عددهای بزرگ تیتر نه؛ ارقام فارسی هم‌عرض در اندازهٔ بزرگ پراکنده به نظر می‌رسند. بیشتر دربارهٔ فونت در [این مقاله](/articles/persian-web-font/).

## رنگ‌ها: از پالت خام به توکن

پالت پیش‌فرض Tailwind (`gray-500`، `teal-600`) برای شروع خوب است، ولی در محصول واقعی همان مشکل رنگ‌های سخت‌کدشده را می‌سازد: تم تیره و تغییر برند سخت می‌شود. بهتر است رنگ‌ها را به [توکن‌های معنایی](/articles/design-tokens-guide/) وصل کنید تا کلاس‌ها نقش را بگویند، نه رنگ را:

```html
<!-- رنگ خام -->
<div class="bg-white text-gray-900 border-gray-200 dark:bg-gray-900 dark:text-white">

<!-- نقش، با تم تیره به‌طور خودکار -->
<div class="bg-primary text-primary border-secondary">
```

<Figure n={3} alt="کارتی که با کلاس‌های Tailwind متصل به توکن‌های کاشی ساخته شده، در تم روشن و تیره بدون کلاس dark" caption="وقتی کلاس‌ها به توکن وصل‌اند، تم تیره بدون حتی یک کلاس dark: کار می‌کند." />

پکیج [`@kashi-ui/tailwind`](/docs/tailwind/) همین کار را می‌کند: توکن‌های کاشی را به‌شکل کلاس‌های آشنای Tailwind (`bg-secondary`، `text-tertiary`، `rounded-lg`، `shadow-md`) در اختیارتان می‌گذارد و با تم تیره و رنگ برند شما هماهنگ است:

```css
@import "@kashi-ui/tailwind";
@import "tailwindcss";
@import "@kashi-ui/css";
```

## جمع‌بندی

Tailwind برای فارسی آماده است، به شرطی که از کلاس‌های منطقی (`ms`، `pe`، `start`، `text-start`) استفاده کنید، `rtl:` را فقط برای استثناها نگه دارید، فونت فارسی را در تم تعریف کنید و رنگ‌ها را به توکن وصل کنید. با این چهار قاعده، کد Tailwind شما هم فارسی است و هم برای روزی که نسخهٔ انگلیسی بخواهید آماده.
