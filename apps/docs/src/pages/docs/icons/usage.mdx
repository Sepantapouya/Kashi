آیکون‌های کاشی برای خود کاشی طراحی شده‌اند؛ همان سبکی که داخل دکمه‌ها، فیلدها و هشدارها می‌بینید. همه با `currentColor` رنگ می‌گیرند، پس رنگ متن اطراف را به ارث می‌برند و در تم تیره و روشن درست دیده می‌شوند. مجوز MIT است و در هر پروژه‌ای، حتی تجاری، آزادانه قابل استفاده‌اند.

<Install command="npm i @kashi-ui/icons" />

همهٔ آیکون‌ها را دسته به دسته در [فهرست آیکون‌ها](/docs/icons/) ببینید.

## شش سبک

هر آیکون در شش سبک هست و همه از یک طرح خطی ساخته می‌شوند: `light` (خطی، پیش‌فرض)، `bold` (توپر)، `bulk` (حجمی)، `two-tone` (دورنگ)، `broken` (شکسته) و `curved` (منحنی).

```tsx
<IconWallet variant="bold" />
<Icon name="calendar" variant="bulk" />
```

```js
iconSvg("heart", { variant: "two-tone" });
```

هر سبک اسپرایت جدای خودش را دارد (`@kashi-ui/icons/sprite-bold.svg` با شناسهٔ `#k-home--bold`) و فایل‌های جدا در `@kashi-ui/icons/svg/<variant>/<name>.svg` هستند. سبک `bold` جزئیات را با ماسک SVG از دل شکل سوراخ می‌کند؛ هر نمونه شناسهٔ ماسک یکتای خودش را می‌گیرد.

## React

هر آیکون یک کامپوننت جداست؛ فقط آیکون‌هایی که import می‌کنید در باندل می‌آیند.

```tsx
import { IconSearch, IconTrash } from "@kashi-ui/icons/react";

<IconSearch />
<IconTrash size={24} strokeWidth={2} className="danger" />
```

وقتی نام آیکون از داده می‌آید، از `Icon` استفاده کنید:

```tsx
import { Icon } from "@kashi-ui/icons/react";

<Icon name={item.icon} />
```

| ویژگی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `size` | `number \| string` | `20` | عرض و ارتفاع؛ عدد یعنی پیکسل، یا هر واحد CSS مثل `"1.25em"` |
| `strokeWidth` | `number` | `1.5` | ضخامت خط |
| `title` | `string` | — | متن برای صفحه‌خوان؛ بدون آن آیکون تزئینی و پنهان است |
| `mirror` | `boolean` | `false` | قرینهٔ افقی؛ برای فلش‌ها در طرح‌های دوجهته |
| `name` | `IconName` | — | فقط در `Icon`؛ نام آیکون |

بقیهٔ ویژگی‌های `<svg>` (مثل `className`، `style` و `onClick`) هم پذیرفته می‌شوند و `ref` به خود `<svg>` می‌رسد.

## HTML و فریم‌ورک‌های دیگر

برای Vue، Svelte، Angular یا HTML ساده سه راه دارید.

**۱. کد SVG با جاوااسکریپت.** `iconSvg` رشتهٔ SVG برمی‌گرداند:

```js
import { iconSvg } from "@kashi-ui/icons";

button.innerHTML = iconSvg("trash", { size: 16 }) + " حذف";
```

**۲. اسپرایت.** فایل `@kashi-ui/icons/sprite.svg` را یک بار در صفحه بگذارید یا کنار سایتتان منتشر کنید و هر جا لازم شد صدا بزنید:

```html
<svg width="20" height="20" aria-hidden="true">
  <use href="/sprite.svg#k-search" />
</svg>
```

**۳. فایل SVG جدا.** هر آیکون در `@kashi-ui/icons/svg/<name>.svg` هم هست؛ برای `<img>` یا ابزارهای ساخت که SVG را import می‌کنند.

## داخل کامپوننت‌های کاشی

آیکون‌ها برای کار کنار کامپوننت‌ها ساخته شده‌اند و اندازه‌شان با دکمه و فیلد هماهنگ است:

```tsx
import { Button, Input } from "@kashi-ui/react";
import { IconPlus, IconSearch } from "@kashi-ui/icons/react";

<Button variant="primary" iconStart={<IconPlus />}>پروژهٔ جدید</Button>
<Input addonStart={<IconSearch />} placeholder="جستجو" />
```

## دسترس‌پذیری

- آیکون بدون `title` با `aria-hidden` از صفحه‌خوان پنهان می‌شود؛ برای آیکون‌هایی که کنار متن می‌آیند همین درست است.
- آیکونی که تنها می‌آید و معنا دارد (مثل دکمهٔ فقط‌آیکون) باید نام داشته باشد: یا `title` بدهید، یا بهتر، `aria-label` را روی خود دکمه بگذارید.
- آیکون‌ها `focusable="false"` دارند تا در اینترنت اکسپلورر و نسخه‌های قدیمی Edge در ترتیب Tab نیایند.

## راست‌به‌چپ

آیکون‌ها به‌طور پیش‌فرض قرینه نمی‌شوند؛ `arrow-left` همیشه به چپ اشاره می‌کند. در رابط فارسی، «بعدی» و «ادامه» یعنی فلش چپ و «بازگشت» یعنی فلش راست. شش آیکون جهت‌دار (فلش‌ها، شورون‌های چپ و راست، ارسال و خروج) در صفحهٔ هر آیکون با نشان «جهت‌دار» مشخص‌اند. اگر طرح شما هم راست‌به‌چپ و هم چپ‌به‌راست است، با `mirror` قرینه‌شان کنید.

## فیگما

همهٔ آیکون‌ها در صفحهٔ «🧩 Icons» [پلاگین فیگمای کاشی](/docs/figma/) هم هستند، دسته‌به‌دسته، هر کدام به شکل کامپوننت با نام `Icon / <دسته> / <name>` تا در پنل Assets هم پوشه‌بندی شوند؛ با Instance swap داخل دکمه‌ها و فیلدها عوض می‌شوند. فیگما و کد از یک منبع ساخته می‌شوند، پس شکل آیکون‌ها در هر دو یکی است.
