## کدام را انتخاب کنم؟

- **محصول فارسی یا ایرانی می‌سازید:** کاشی. جستجوی فارسی، لوگوی بانک‌ها و درگاه‌ها، حروف فارسی و آیکون‌های جهت‌دار برای راست‌به‌چپ را جای دیگری پیدا نمی‌کنید، و کامپوننت‌های کاشی هم همین آیکون‌ها را دارند.
- **آیکون سه‌بعدی یا تصویرسازی متحرک لازم دارید و بودجه دارید:** Iconly Pro. مجموعهٔ بزرگ‌تری از آیکون‌های سه‌بعدی و متحرک دارد.
- **فقط یک مجموعهٔ خطی سبک و شناخته‌شده برای اپ انگلیسی می‌خواهید:** Lucide. جامعهٔ بزرگی دارد و بسته‌اش برای بیشتر فریم‌ورک‌ها هست.
- **Flutter یا فونت آیکون لازم دارید:** فعلاً Phosphor. کاشی هنوز این دو را ندارد.
