## گزارش آسیب‌پذیری

اگر در کاشی مشکل امنیتی پیدا کرده‌اید، **آن را در Issue عمومی ننویسید.** از گزارش خصوصی GitHub استفاده کنید تا تا زمان رفع، فقط نگهدارندهٔ کاشی آن را ببیند:

**[گزارش خصوصی آسیب‌پذیری](https://github.com/Sepantapouya/Kashi/security/advisories/new)**

لطفاً بنویسید کدام پکیج و نسخه، مشکل چیست، چطور می‌شود آن را تکرار کرد و چه اثری دارد. اگر راه رفعی به ذهنتان رسیده، آن را هم بنویسید.

## زمان پاسخ

| مرحله | زمان |
|---|---|
| تأیید دریافت گزارش | تا ۳ روز کاری |
| بررسی و تعیین شدت | تا ۷ روز کاری |
| رفع آسیب‌پذیری بحرانی و شدید | تا ۱۴ روز |
| رفع آسیب‌پذیری متوسط و کم | در نسخهٔ بعدی |

پس از انتشار نسخهٔ رفع‌شده، یک GitHub Security Advisory با شمارهٔ CVE (در صورت نیاز) منتشر و از گزارش‌دهنده، اگر بخواهد، نام برده می‌شود. لطفاً پیش از انتشار رفع، جزئیات را جایی منتشر نکنید.

## نسخه‌های پشتیبانی‌شده

| نسخه | رفع امنیتی |
|---|---|
| ۱.x | ✓ |
| ۰.x | ✗ (به ۱.۰ مهاجرت کنید؛ تغییر کدی لازم ندارد) |

پس از انتشار نسخهٔ ۲.۰، رفع‌های امنیتی ۱.x تا ۱۲ ماه ادامه دارد. [سیاست تغییرات](/docs/versioning/)

## کاشی برای امنیت چه می‌کند

- **وابستگی کم:** `@kashi-ui/persian`، `@kashi-ui/tokens`، `@kashi-ui/icons` و `@kashi-ui/tailwind` هیچ وابستگی‌ای ندارند. `@kashi-ui/react` و `@kashi-ui/elements` فقط به پکیج‌های خود کاشی وابسته‌اند (و React). تنها استثنا سرور MCP است که از SDK رسمی MCP استفاده می‌کند.
- **بدون اجرای کد هنگام نصب:** هیچ پکیج کاشی اسکریپت `install` یا `postinstall` ندارد.
- **بدون ارسال داده:** کامپوننت‌ها هیچ درخواستی به اینترنت نمی‌فرستند. لوگوی بانک‌ها و فونت داخل پکیج‌اند.
- **متن کاربر به‌شکل متن:** کامپوننت‌های React متن را هرگز به‌شکل HTML خام نمی‌نویسند و وب کامپوننت‌ها مقدارها و ویژگی‌ها را پیش از ساختن HTML امن (escape) می‌کنند.
- **بررسی خودکار وابستگی‌ها:** در هر تغییر، `npm audit` اجرا می‌شود و آسیب‌پذیری شدید جلوی ادغام را می‌گیرد.
- **حساب انتشار** با ورود دومرحله‌ای محافظت می‌شود.

## اگر از کاشی در محصولتان استفاده می‌کنید

- پکیج‌ها را با `^1` نصب کنید تا رفع‌های امنیتی با `npm update` برسد.
- برای خبر شدن از نسخه‌های امنیتی، در GitHub روی **Watch ← Custom ← Security alerts** بزنید.
