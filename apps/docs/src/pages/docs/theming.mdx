## تم‌ساز

تغییرات روی کل همین صفحه اعمال می‌شوند. کد تولیدشده را کپی کنید و در CSS پروژه بگذارید.

## چهار لایهٔ سفارشی‌سازی

### ۱. رنگ برند

همهٔ کامپوننت‌ها رنگ برند را از طیف `--k-brand-50` تا `--k-brand-950` می‌خوانند. تابع `createTheme()` این طیف را از یک رنگ می‌سازد:

```ts
import { createTheme } from "@kashi-ui/tokens";

const css = createTheme({ brand: "#7c3aed" });
// css را در یک تگ <style> یا فایل CSS قرار دهید
```

اگر طیف دقیق برندتان را دارید، آن را مستقیم بدهید:

```ts
createTheme({ brand: { 50: "#f5f3ff", 100: "#ede9fe", /* … */ 950: "#2e1065" } });
```

### ۲. پیچ‌های سراسری

| متغیر | پیش‌فرض | اثر |
|---|---|---|
| `--k-radius-factor` | `1` | ضریب همهٔ گوشه‌ها؛ `0` تیز، `2` بسیار گرد |
| `--k-density` | `1` | ضریب ارتفاع و فاصلهٔ داخلی کنترل‌ها؛ `0.875` فشرده |
| `--k-font-sans` | وزیرمتن | فونت اصلی؛ راهنمای کامل در [فونت و تایپوگرافی](/docs/typography/) |
| `--k-text-scale` | `1` | ضریب اندازهٔ همهٔ متن‌ها |

### ۳. متغیرهای هر کامپوننت

هر کامپوننت متغیرهای عمومی با الگوی `--k-{کامپوننت}-{ویژگی}` دارد. فهرست کامل در صفحهٔ هر کامپوننت آمده است.

```css
:root {
  --k-btn-radius: 999px;      /* دکمه‌های کاملاً گرد */
  --k-input-height-md: 3rem;  /* فیلدهای بلندتر */
}

/* فقط در یک بخش خاص */
.checkout {
  --k-card-padding: 2rem;
}
```

### ۴. بازنویسی مستقیم

همهٔ استایل‌های کاشی در Cascade Layer با نام `kashi` قرار دارند. هر CSS معمولی شما، با هر میزان اختصاصی بودن، روی آن‌ها اولویت دارد:

```css
/* بدون !important کار می‌کند */
.k-btn { letter-spacing: 0; }
```

> **دام رایج: استایل‌های سراسری عناصر.** چون CSS شما همیشه بر کاشی اولویت دارد، قاعده‌ای مثل `a { color: blue }` رنگ دکمه‌ای را هم که با `<a class="k-btn">` ساخته شده عوض می‌کند. دو راه حل:
>
> ```css
> /* ۱. دکمه‌ها را مستثنا کنید و اختصاصی بودن را صفر نگه دارید */
> :where(a:not(.k-btn)) { color: blue; }
>
> /* ۲. یا ریست‌ها و استایل‌های پایهٔ خودتان را در لایه‌ای پیش از کاشی بگذارید */
> @layer my-reset, kashi;
> @layer my-reset { a { color: blue; } }
> ```

## تم روشن و تیره

تم پیش‌فرض تیره است. ویژگی `data-theme` را روی `<html>` یا هر عنصری بگذارید:

```html
<html data-theme="light">
<section data-theme="dark">…</section>
```

برای پیروی از تنظیم سیستم کاربر:

```js
const dark = matchMedia("(prefers-color-scheme: dark)").matches;
document.documentElement.dataset.theme = dark ? "dark" : "light";
```

> طیفی که `createTheme()` می‌سازد خودکار از نظر کنتراست بررسی نمی‌شود. پس از انتخاب رنگ برند، کنتراست دکمهٔ اصلی را بررسی کنید.
