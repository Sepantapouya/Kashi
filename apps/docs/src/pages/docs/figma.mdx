پلاگین **Kashi UI Kit** کل دیزاین‌سیستم کاشی را از روی همین کد در فیگما می‌سازد. رنگ‌ها، فاصله‌ها، فونت و اندازهٔ کامپوننت‌ها مستقیم از پکیج‌های `@kashi-ui` خوانده می‌شوند؛ پس آنچه طراح در فیگما می‌بیند، پیکسل‌به‌پیکسل همان چیزی است که برنامه‌نویس در کد می‌سازد.

<p><a class="k-btn k-btn--primary k-btn--lg" href="/downloads/kashi-figma-plugin.zip" download>دانلود پلاگین فیگما</a></p>

## چه چیزهایی ساخته می‌شود

| بخش | جزئیات |
|---|---|
| **Variables** | حدود ۲۷۰ متغیر در ۶ مجموعه: پالت، تم (تیره و روشن)، گردی، فاصله، تراکم و تایپوگرافی |
| **کامپوننت‌ها** | بیش از ۷۰ کامپوننت با حدود ۷۰۰ variant؛ هر کامپوننت در یک صفحهٔ جدا |
| **فارسی** | کارت بانکی با لوگوی بانک، شبا، کد ملی، موبایل، پلاک، مبلغ، تقویم شمسی، رسید پرداخت و … |
| **Assets** | ۷۰ آیکون و ۵۰ لوگوی بانک و درگاه پرداخت، هر کدام به شکل کامپوننت |
| **صفحهٔ جلد** | معرفی کیت و راهنمای شروع سریع |

همه‌چیز **Variable** است، نه Style: رنگ متن‌ها و پس‌زمینه‌ها، اندازه و وزن و ارتفاع خط فونت‌ها، و حتی رنگ و فاصلهٔ هر لایهٔ سایه. یعنی با عوض کردن یک متغیر، همهٔ کامپوننت‌ها با هم عوض می‌شوند.

صفحه‌ها در فیگما گروه‌بندی شده‌اند و بین هر گروه یک جداکننده است:

```text
📕 Kashi UI Kit

🎨 Colors · Semantic colors · Typography · Spacing · Radius · Shadows
———————
🧩 Icons · Bank logos
———————
🔘 Button · Icon button · Button group · …
📝 Input · Select · Checkbox · Date picker · …
🇮🇷 Card number input · IBAN input · Plate input · …
💬 Alert · Toast · Dialog · …
📊 Badge · Avatar · Card · Table · …
🧭 Tabs · Breadcrumb · Pagination · …
```

## نصب

۱. [فایل پلاگین](/downloads/kashi-figma-plugin.zip) را دانلود و از حالت فشرده خارج کنید.
۲. اپ **دسکتاپ** فیگما را باز کنید. نسخهٔ مرورگر، پلاگین‌هایی را که روی کامپیوتر شما هستند اجرا نمی‌کند.
۳. یک فایل فیگما باز کنید، ترجیحاً یک فایل خالی برای کتابخانهٔ تیم.
۴. از منوی بالا بروید به **Plugins ← Development ← Import plugin from manifest…** و فایل `manifest.json` را از پوشهٔ دانلودشده انتخاب کنید.

این کار فقط یک بار لازم است.

## اجرا

۱. **Plugins ← Development ← Kashi UI Kit**
۲. تم پیش‌فرض صفحه‌ها و فونت را انتخاب کنید.
۳. دکمهٔ **ساخت کیت** را بزنید. ساخت کامل حدود یک دقیقه طول می‌کشد.

برای استفاده در فایل‌های دیگر تیم، از پنل Assets فیگما فایل را **Publish** کنید تا کتابخانهٔ کاشی در همهٔ فایل‌ها در دسترس باشد.

## به‌روزرسانی با نسخه‌های جدید

لازم نیست برای هر نسخهٔ جدید فایل تازه بسازید. پلاگین نسخهٔ جدید را دانلود و دوباره import کنید، سپس در **همان فایل** اجرایش کنید:

- **کامپوننت‌های جدید** صفحهٔ خودشان را می‌گیرند و سر جایشان در فهرست صفحه‌ها اضافه می‌شوند.
- **کامپوننت‌هایی که در کد بهتر شده‌اند** درجا به‌روز می‌شوند. همان کامپوننت باقی می‌ماند و فقط ظاهرش عوض می‌شود، پس instance هایی که در طرح‌هایتان گذاشته‌اید **وصل می‌مانند** و تغییر را خودکار می‌گیرند.
- **متن‌هایی که از پنل Properties عوض کرده‌اید** (مثل متن دکمه) حفظ می‌شوند.
- **صفحه‌هایی که خودتان ساخته‌اید** دست نمی‌خورند؛ بعد از صفحه‌های کیت می‌مانند.
- اگر یک صفحهٔ کیت را اشتباهی پاک کرده باشید، دوباره ساخته می‌شود.

پنل پلاگین نسخهٔ نصب‌شده در فایل را نشان می‌دهد و دکمه به «به‌روزرسانی به نسخهٔ …» تغییر می‌کند. در پایان هم می‌گوید چند مورد اضافه و چند مورد به‌روز شد.

> اگر فقط می‌خواهید رنگ‌ها یا فونت را به‌روز کنید، تیک «صفحه‌های کامپوننت» را بردارید تا فقط متغیرها به‌روز شوند. این کار چند ثانیه بیشتر طول نمی‌کشد.

## سفارشی‌سازی

### تم تیره و روشن

یک فریم یا کل صفحه را انتخاب کنید و در پنل سمت راست، بخش **Appearance** (یا Layer)، مجموعهٔ `Kashi · Theme` را روی **Dark** یا **Light** بگذارید. هر بخش از طرح می‌تواند تم خودش را داشته باشد.

### رنگ برند

در **Local variables ← Kashi · Primitives**، متغیرهای `color/brand/50` تا `color/brand/950` را به رنگ دیگری از پالت وصل کنید (مثلاً `color/lajvard/*`). همهٔ دکمه‌ها، فیلدها، تب‌ها و حلقه‌های فوکوس با هم عوض می‌شوند. این همان کاری است که `createTheme({ brand })` در کد انجام می‌دهد.

### فونت دلخواه، حتی فونت پولی

دو راه دارید:

- نام فونت را در پنل پلاگین بنویسید (مثلاً `IRANSans` یا `Yekan Bakh`) و دوباره اجرا کنید. پلاگین وزن‌های موجود فونت را پیدا می‌کند و اگر وزنی نباشد، نزدیک‌ترین وزن را جایگزین می‌کند.
- یا در **Kashi · Typography** مقدار `font/family/sans` (و `font/family/display` برای عنوان‌ها) را عوض کنید.

فونت باید روی کامپیوتر شما نصب باشد. اگر پیدا نشود، وزیرمتن استفاده می‌شود.

### گردی، تراکم و اندازهٔ متن

| مجموعه | mode ها | معادل در کد |
|---|---|---|
| `Kashi · Radius` | Default، Sharp، Soft، Round | `--k-radius-factor` |
| `Kashi · Density` | Default، Compact، Comfortable | `--k-density` |
| `Kashi · Typography` | Default، Compact، Large | `--k-text-scale` |

> پلن رایگان فیگما برای هر مجموعه فقط یک mode اجازه می‌دهد. روی پلن رایگان، پلاگین فقط تمی را که انتخاب کرده‌اید می‌سازد و بقیهٔ mode ها را رد می‌کند.

## از فیگما تا کد

نام کامپوننت‌ها و ویژگی‌ها همان prop های React است:

| فیگما | React |
|---|---|
| `Button` → `Variant=Primary, Size=md` | `<Button variant="primary" size="md">` |
| `Badge` → `Tone=Success, Variant=Soft` | `<Badge tone="success" variant="soft">` |
| `Input` → `Size=lg, State=Error` | `<Input size="lg" error="…">` |
| متغیر `bg/brand` | `var(--k-bg-brand)` |
| متغیر `space/4` | `var(--k-space-4)` |

هر کامپوننت در فیگما یک لینک **Documentation** دارد که مستقیم به صفحهٔ همان کامپوننت در این سایت می‌آید.

## هم‌خوانی پیکسلی با کد

ارتفاع، فاصلهٔ داخلی و گردی کامپوننت‌ها با CSS واقعی کاشی در مرورگر اندازه‌گیری شده و در یک تست خودکار با خروجی پلاگین مقایسه می‌شود. اگر روزی کد و فیگما از هم فاصله بگیرند، ساخت پروژه شکست می‌خورد.

## برای توسعه‌دهنده‌ها

کد پلاگین در [`apps/figma-plugin`](https://github.com/Sepantapouya/Kashi/tree/main/apps/figma-plugin) است.

```bash
npm run figma:build   # ساخت پلاگین از روی توکن‌ها و کد
npm run figma:test    # اجرای کامل در شبیه‌ساز API فیگما و تست هم‌خوانی پیکسلی
```
