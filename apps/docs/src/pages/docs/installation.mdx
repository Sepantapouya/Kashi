## پکیج npm

راه پیشنهادی برای بیشتر پروژه‌ها. کامپوننت‌ها از پکیج می‌آیند و با به‌روز کردن پکیج، اصلاح‌ها و کامپوننت‌های تازه هم می‌رسند.

```bash
npm i @kashi-ui/react @kashi-ui/css
```

فایل CSS را یک بار در ریشهٔ برنامه وارد کنید و جهت صفحه را راست‌به‌چپ قرار دهید:

```tsx
// main.tsx یا app/layout.tsx
import "@kashi-ui/css";
```

```html
<html lang="fa" dir="rtl">
```

حالا کامپوننت‌ها آمادهٔ استفاده‌اند:

```tsx
import { Button } from "@kashi-ui/react";

export function Example() {
  return <Button variant="primary">ثبت‌نام</Button>;
}
```

کاشی با React نسخهٔ ۱۸ و ۱۹ کار می‌کند و با Next.js، Vite و Remix سازگار است. در App Router نکست می‌شود کامپوننت‌ها را مستقیم در صفحه‌های سرور هم استفاده کرد.

## رجیستری shadcn

اگر می‌خواهید کد خودِ کامپوننت در پروژه‌تان باشد و هر تغییری خواستید در آن بدهید، از رجیستری کاشی با ابزار [shadcn](https://ui.shadcn.com/docs/cli) استفاده کنید. فایل‌ها در پوشهٔ `components/kashi` کپی می‌شوند و کامپوننت‌هایی که به آن‌ها وابسته‌اند، CSS کاشی و ابزارهای فارسی هم خودکار نصب می‌شوند.

```bash
npx shadcn@latest add https://kashi.sepantapouya.com/r/iran-map.json
```

```tsx
import { IranMap } from "@/components/kashi/IranMap";
```

روی هر کامپوننت بزنید تا دستور نصبش کپی شود:

<InstallKit part="registry" />

برای دستور کوتاه‌تر، رجیستری کاشی را یک بار در `components.json` معرفی کنید:

```json
{
  "registries": {
    "@kashi": "https://kashi.sepantapouya.com/r/{name}.json"
  }
}
```

```bash
npx shadcn@latest add @kashi/date-picker @kashi/iran-map
```

پروژه باید پیش‌تر با `npx shadcn@latest init` آماده شده باشد. فهرست کامل آیتم‌ها در [registry.json](/r/registry.json) است.

### npm یا shadcn؟

| | پکیج npm | رجیستری shadcn |
|---|---|---|
| کد کامپوننت | داخل `node_modules` | داخل پروژهٔ شما |
| تغییر دادن کد | با props، کلاس و متغیرهای CSS | هر تغییری، مستقیم در فایل |
| به‌روزرسانی | با `npm update` | با اجرای دوبارهٔ دستور (تغییرهای شما بازنویسی می‌شود) |
| مناسب برای | بیشتر پروژه‌ها | تیم‌هایی که کد را از آنِ خود می‌خواهند |

## Tailwind

اگر پروژه‌تان Tailwind دارد، پریست کاشی را هم نصب کنید تا رنگ‌ها، فونت، گردی و سایه‌های کاشی به‌شکل کلاس‌های Tailwind (`bg-brand`، `rounded-lg`، `text-secondary`) در دسترس باشند و با تم تیره و روشن همگام بمانند:

```bash
npm i @kashi-ui/tailwind
```

```css
@import "@kashi-ui/tailwind";
@import "tailwindcss";
@import "@kashi-ui/css";
```

راهنمای کامل، فهرست کلاس‌ها و تنظیم Tailwind 3: [Tailwind](/docs/tailwind/)

## HTML و فریم‌ورک‌های دیگر

برای Vue، Svelte، Angular، وردپرس یا HTML ساده دو پکیج دارید: `@kashi-ui/css` برای ظاهر همهٔ کامپوننت‌ها و `@kashi-ui/elements` برای کامپوننت‌هایی که JavaScript لازم دارند (فیلدهای فارسی، تقویم شمسی، کد تأیید، پنجره، زبانه و اعلان) به‌شکل وب کامپوننت.

```bash
npm i @kashi-ui/css @kashi-ui/elements
```

یا بدون نصب، از CDN:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@kashi-ui/css/dist/kashi.css">
<script type="module" src="https://cdn.jsdelivr.net/npm/@kashi-ui/elements/dist/cdn/kashi-elements.js"></script>
```

سپس از کلاس‌ها و تگ‌ها استفاده کنید. نمونهٔ HTML هر کامپوننت در صفحهٔ همان کامپوننت آمده است.

```html
<button class="k-btn k-btn--primary">ثبت‌نام</button>
<kashi-national-id name="national_id" required></kashi-national-id>
<kashi-date-picker label="تاریخ تولد" name="birth"></kashi-date-picker>
```

فهرست همهٔ وب کامپوننت‌ها، رویدادها و تنظیم Vue و Angular: [وب کامپوننت‌ها](/docs/web-components/)

## وارد کردن بخشی از CSS

اگر فقط به چند کامپوننت نیاز دارید، فایل‌ها را جداگانه وارد کنید. ترتیب مهم است: توکن‌ها، فونت و پایه، سپس کامپوننت‌ها.

```css
@import "@kashi-ui/css/tokens.css";
@import "@kashi-ui/css/font.css";
@import "@kashi-ui/css/base.css";
@import "@kashi-ui/css/components/button.css";
@import "@kashi-ui/css/components/input.css";
```

> فایل‌های جداگانه در Cascade Layer قرار ندارند. اگر به اولویت لایه‌ها نیاز دارید، از فایل کامل `kashi.css` استفاده کنید.

## تم روشن

تم پیش‌فرض تیره است. برای تم روشن، ویژگی `data-theme` را روی هر عنصری بگذارید؛ زیرشاخهٔ آن عنصر روشن می‌شود.

```html
<html lang="fa" dir="rtl" data-theme="light">
```
