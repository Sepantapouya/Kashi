حرکت در کاشی تزئین نیست؛ بازخورد است. وقتی کاربر دکمه‌ای را فشار می‌دهد، تیکی می‌زند یا گزینه‌ای را عوض می‌کند، یک حرکت کوتاه می‌گوید «دیدم، انجام شد». همه‌چیز کوتاه، آرام و از توکن‌های مشترک است، و اگر کاربر در سیستم‌عاملش «کاهش حرکت» را روشن کرده باشد، خاموش می‌شود.

## توکن‌ها

| توکن | مقدار | کجا |
| --- | --- | --- |
| `--k-duration-fast` | ۱۲۰ میلی‌ثانیه | فشردن، hover، رنگ |
| `--k-duration-normal` | ۲۰۰ میلی‌ثانیه | تیک، باز شدن فهرست، پیام خطا |
| `--k-duration-slow` | ۳۲۰ میلی‌ثانیه | لغزیدن دستگیرهٔ سگمنت و زبانه، پر شدن نوار |
| `--k-ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | بیشتر حرکت‌ها؛ تند شروع و نرم تمام می‌شود |
| `--k-ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | بازخورد کوچک با کمی جهش: تیک، دستگیره، فشردن |
| `--k-ease-emphasized` | `cubic-bezier(0.3, 0, 0, 1.3)` | ورود پنجره و نمایش مهم |
| `--k-ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | بسته شدن؛ همیشه سریع‌تر از باز شدن |

```css
.my-card { transition: translate var(--k-duration-normal) var(--k-ease-spring); }
.my-card:hover { translate: 0 -2px; }
```

## قاعده‌ها

1. **هر حرکت یک معنا دارد.** فشرده شدن یعنی «کلیک گرفته شد»، جهش تیک یعنی «انجام شد»، لرزش یعنی «اشتباه است». حرکتی که چیزی نمی‌گوید حذف می‌شود.
2. **کوتاه.** بازخورد زیر ۲۰۰ میلی‌ثانیه، جابه‌جایی زیر ۳۲۰ میلی‌ثانیه. کاربر نباید منتظر انیمیشن بماند.
3. **بسته شدن سریع‌تر از باز شدن.** پنجره با `ease-emphasized` می‌آید و با `ease-exit` و `duration-fast` می‌رود.
4. **کوچک.** جابه‌جایی چند پیکسل و تغییر اندازهٔ دو تا سه درصد کافی است؛ چیزی نباید از جایش بپرد.
5. **هم‌جهت با خواندن.** درخشش اسکلتون در فارسی از راست به چپ می‌رود و در انگلیسی برعکس؛ فلش دکمهٔ «ادامه» با hover به سمت جلو (در فارسی چپ) می‌رود.
6. **بدون حرکت هم کامل است.** با «کاهش حرکت» همه‌چیز فوری عوض می‌شود و هیچ اطلاعاتی فقط با حرکت گفته نمی‌شود.

## ریزتعامل هر کامپوننت

- **دکمه:** با کلیک کمی فشرده می‌شود؛ آیکون انتهای دکمه با hover کمی جلو می‌رود؛ دکمهٔ کپی بعد از کپی تیک سبز با جهش نشان می‌دهد.
- **سوییچ:** دستگیره هنگام فشردن به سمت مقصد کش می‌آید و با فنر جا می‌افتد.
- **چک‌باکس و رادیو:** تیک و نقطه از مرکز با جهش ظاهر می‌شوند و خود کنترل هنگام کلیک کمی فشرده می‌شود.
- **چیپ:** تیک انتخاب با جهش ظاهر می‌شود.
- **سگمنت و زبانه‌ها:** دستگیرهٔ انتخاب بین گزینه‌ها می‌لغزد، نه اینکه بپرد.
- **فیلدها:** وقتی خطا ظاهر می‌شود، فیلد یک بار کوتاه می‌لرزد و پیام خطا نرم از بالا می‌آید.
- **سلکت، منو، پاپ‌اور و تقویم:** از سمت فیلد با کمی بزرگ شدن باز می‌شوند؛ فهرستی که بالای فیلد باز می‌شود، از پایین می‌آید.
- **آکاردئون:** ارتفاع نرم باز می‌شود، شورون با فنر می‌چرخد و متن نرم ظاهر می‌شود.
- **پنجره:** با کمی بزرگ شدن می‌آید و سریع و نرم می‌رود؛ پس‌زمینه محو می‌شود.
- **نمونهٔ رنگ:** حلقهٔ برند و تیک با جهش.
- **نمودار، نوار پیشرفت و گیج:** خط کشیده می‌شود، ستون‌ها از پایین رشد می‌کنند و نوارها نرم پر می‌شوند.
- **اسکلتون:** درخشش ملایم هم‌جهت با خواندن.

## کاهش حرکت

کاشی `prefers-reduced-motion: reduce` را رعایت می‌کند: مدت همهٔ انیمیشن‌ها و ترنزیشن‌ها تقریباً صفر می‌شود، پس تغییر حالت‌ها فوری و بدون حرکت انجام می‌شوند. در CSS خودتان هم همین را بنویسید:

```css
@media (prefers-reduced-motion: reduce) {
  .my-card { transition: none; }
}
```
