با پریست `@kashi-ui/tailwind`، توکن‌های کاشی در پروژهٔ Tailwind شما به‌شکل کلاس‌های آشنا در دسترس‌اند. کامپوننت‌های کاشی همان‌طور که هستند کار می‌کنند و برای بخش‌های دلخواه صفحه، به‌جای `bg-[var(--k-bg-secondary)]` می‌نویسید `bg-secondary`.

```tsx
<div className="bg-secondary border border-brand rounded-lg shadow-md p-4">
  <h3 className="text-primary text-lg font-semibold">سفارش‌های امروز</h3>
  <p className="text-tertiary text-sm">۱۲ سفارش تازه</p>
  <Button variant="primary">مشاهده</Button>
</div>
```

کلاس‌ها کپی رنگ‌ها نیستند؛ همه به همان متغیرهای کاشی (`var(--k-…)`) اشاره می‌کنند. پس تم تیره و روشن، رنگ برندی که با `createTheme` ساخته‌اید و هر نسخهٔ جدید کاشی، بدون هیچ کاری روی کلاس‌های Tailwind هم اعمال می‌شود. ساختار کاشی هم هیچ تغییری نمی‌کند؛ این پکیج فقط یک پل است.

## نصب

```bash
npm i @kashi-ui/react @kashi-ui/css @kashi-ui/tailwind
```

### Tailwind 4

در فایل CSS اصلی پروژه (مثلاً `app/globals.css`):

```css
@import "@kashi-ui/tailwind";
@import "tailwindcss";
@import "@kashi-ui/css";
```

> **ترتیب مهم است:** `@kashi-ui/tailwind` باید **اول** بیاید. این فایل ترتیب لایه‌های CSS را تعیین می‌کند تا کلاس‌های Tailwind همیشه بر استایل کامپوننت‌های کاشی برنده باشند؛ مثلاً `<Button className="rounded-none">` واقعاً گوشه‌ها را تیز کند. با ترتیب دیگر، استایل کاشی برنده می‌شود.

### Tailwind 3

در `tailwind.config.js` پریست را اضافه کنید و CSS کاشی را مثل همیشه وارد کنید:

```js
module.exports = {
  presets: [require("@kashi-ui/tailwind/preset")],
  content: ["./src/**/*.{js,ts,jsx,tsx}"],
};
```

```tsx
import "@kashi-ui/css";
```

## کلاس‌ها

### رنگ‌های معنایی

همان نام‌های توکن‌های کاشی، بدون پیشوند. این‌ها با تم تیره و روشن عوض می‌شوند و برای بیشتر رابط کاربری کافی‌اند.

| کلاس | نمونه‌ها |
|---|---|
| `bg-*` | `bg-primary` · `bg-secondary` · `bg-tertiary` · `bg-elevated` · `bg-hover` · `bg-active` · `bg-brand` · `bg-brand-subtle` · `bg-success-subtle` · `bg-error-subtle` · `bg-warning-subtle` · `bg-info-subtle` |
| `text-*` | `text-primary` · `text-secondary` · `text-tertiary` · `text-quaternary` · `text-brand` · `text-on-brand` · `text-success` · `text-error` · `text-warning` · `text-info` |
| `border-*` | `border-primary` · `border-secondary` · `border-brand` · `border-error` · `border-input` |

همهٔ حالت‌های Tailwind هم کار می‌کنند: `hover:bg-hover`، `focus:border-brand`، `md:bg-secondary`.

### طیف رنگ‌ها

طیف برند و رنگ‌های ایرانی کاشی، از ۵۰ تا ۹۵۰، با پشتیبانی از شفافیت (`bg-brand-500/50`):

| طیف | نمونه |
|---|---|
| `brand` | `bg-brand-500` · `text-brand-700`؛ همان رنگی که `createTheme` می‌سازد |
| `firoozeh` (فیروزه) · `lajvard` (لاجورد) · `zafaran` (زعفران) · `anar` (انار) · `pesteh` (پسته) · `shab` (شب) | `bg-firoozeh-100` · `text-anar-600` · `border-lajvard-300` |

### گردی، سایه و متن

| گروه | کلاس‌ها |
|---|---|
| گردی گوشه | `rounded-sm` · `rounded-md` · `rounded-lg` · `rounded-xl` · `rounded-2xl` · `rounded-full`؛ ضریب `--k-radius-factor` روی همه اعمال می‌شود |
| سایه | `shadow-xs` تا `shadow-2xl` و `shadow-skeuomorphic` |
| فونت | `font-sans` (وزیرمتن یا فونت شما) · `font-display` · `font-mono` |
| اندازهٔ متن | `text-xs` تا `text-6xl`، با ضریب `--k-text-scale` |
| وزن و ارتفاع خط | `font-regular` تا `font-black` · `leading-tight` · `leading-normal` · `leading-relaxed` |
| لایه | `z-dropdown` · `z-sticky` · `z-overlay` · `z-modal` · `z-toast` |
| حرکت | `ease-standard` · `ease-emphasized` |

فاصله‌ها (`p-4`، `gap-6`، `mt-8`) همان مقیاس پیش‌فرض Tailwind‌اند که با مقیاس کاشی (پله‌های ۴ پیکسلی) یکی است؛ `p-4` در هر دو ۱۶ پیکسل است.

## تم تیره و روشن

کاشی به‌طور پیش‌فرض تیره است و با `data-theme="light"` روی `<html>` روشن می‌شود. حالت‌های `dark:` و `light:` هم از همین پیروی می‌کنند:

```tsx
<div className="shadow-none light:shadow-sm">…</div>
```

برای بیشتر کارها به این حالت‌ها نیازی ندارید؛ رنگ‌های معنایی مثل `bg-secondary` خودشان با تم عوض می‌شوند.

## رنگ برند

تمی که با `createTheme` یا [تم‌ساز](/docs/theming/) می‌سازید، روی کلاس‌های Tailwind هم اعمال می‌شود:

```ts
import { createTheme } from "@kashi-ui/tokens";

const css = createTheme({ brand: "#3d5ef8", radius: 1.5 });
// حالا bg-brand، text-brand و rounded-lg هم لاجوردی و گردتر شده‌اند
```

## راست‌به‌چپ

Tailwind کلاس‌های منطقی دارد که در RTL و LTR درست کار می‌کنند؛ مثل کامپوننت‌های کاشی، به‌جای `ml-*` و `pr-*` از این‌ها استفاده کنید:

| به‌جای | بنویسید |
|---|---|
| `ml-4` / `mr-4` | `ms-4` / `me-4` |
| `pl-4` / `pr-4` | `ps-4` / `pe-4` |
| `left-0` / `right-0` | `start-0` / `end-0` |
| `text-left` | `text-start` |

برای جاهایی که واقعاً به جهت وابسته‌اند، حالت‌های `rtl:` و `ltr:` هم هست، مثل `rtl:rotate-180` برای فلش.
