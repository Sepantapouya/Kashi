## نمونه

پیش‌فرض ساعت کاری رایج ایران است: شنبه تا چهارشنبه ۹ تا ۱۷، پنجشنبه ۹ تا ۱۳ و جمعه تعطیل. با سوییچ هر روز را باز یا بسته کنید و با «افزودن بازهٔ دیگر» شیفت عصر بگذارید. ساعت‌ها با کلیدهای ↑↓ نیم‌ساعت جابه‌جا می‌شوند. بازه‌ای که پایانش پیش از شروع است یا روی بازهٔ دیگر می‌افتد، خطای فارسی می‌گیرد و فرم با آن ارسال نمی‌شود.

<Demo align="stretch" html={false} code={`const [hours, setHours] = useState<WeekHours>();

<BusinessHours name="hours" value={hours} onChange={(week, valid) => valid && setHours(week)} />`}>
  <BusinessHoursDemo client:only="react" />
</Demo>

مقدار، آرایهٔ هفت‌تایی از شنبه تا جمعه است: `{ open: boolean, ranges: { from: "09:00", to: "17:00" }[] }`. بازه‌ای مثل `22:00` تا `02:00` از نیمه‌شب می‌گذرد و تا بامداد روز بعد حساب می‌شود. با `name` کل هفته به شکل JSON در فرم ارسال می‌شود.

## ابزارها برای سرور و نمایش

```ts
import { isOpenAt, summarizeHours, defaultWeekHours } from "@kashi-ui/persian";

isOpenAt(hours);              // الان باز است؟
summarizeHours(hours);        // «شنبه تا چهارشنبه ۰۹:۰۰ تا ۱۷:۰۰؛ پنجشنبه ۰۹:۰۰ تا ۱۳:۰۰؛ جمعه تعطیل»
summarizeHours(hours, { locale: "en" });
```

## انتخاب روزهای هفته

اگر فقط روزها را لازم دارید (روزهای ارسال، روزهای کلاس)، `WeekdayPicker` را استفاده کنید. مقدار شمارهٔ روزهاست: ۰ شنبه تا ۶ جمعه.

## دسترس‌پذیری

- کل فرم یک `<fieldset>` با عنوان است و هر روز سوییچ واقعی (`role="switch"`) با نام همان روز دارد.
- هر بازه گروهی با نام «بازهٔ ۱ شنبه» است و فیلدهای ساعت نام کامل دارند («بازهٔ ۱ شنبه، از»).
- خطای بازه به فیلدهای همان روز وصل است (`aria-describedby`).
- در `WeekdayPicker` هر روز دکمه‌ای با `aria-pressed` است و نام کامل روز را دارد، حتی وقتی فقط «ش» دیده می‌شود.
