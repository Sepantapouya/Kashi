پلاک نسبت واقعی ۵۲۰ در ۱۱۰ میلی‌متر را دارد و رنگش مثل پلاک واقعی از روی حرف تعیین می‌شود (`plateType`):

| حرف | نوع | رنگ |
|---|---|---|
| ب، ج، د، س… | شخصی | سفید |
| ت / ع / ک | تاکسی / عمومی / کشاورزی | زرد |
| الف | دولتی | قرمز |
| پ / ث | پلیس / سپاه | سبز |
| ش | ارتش | قهوه‌ای روشن |
| ز / ف | وزارت دفاع / ستاد کل | آبی روشن |
| ژ | معلولین | سفید |

ارتفاع با `--k-plate-height` (پیش‌فرض 3.5rem) عوض می‌شود و عرض به همان نسبت تغییر می‌کند. با پر شدن هر بخش، فوکوس به بخش بعد می‌رود و <kbd>Backspace</kbd> در بخش خالی به بخش قبل برمی‌گردد. `formatPlate` متن خوانا می‌سازد: «۱۲ ب ۳۴۵ ایران ۶۷».

## دسترس‌پذیری

یک `role="group"` با نام «پلاک خودرو» و چهار کنترل که هرکدام نام خودش را دارد («دو رقم اول پلاک»، «حرف پلاک»…). حرف با `<select>` بومی انتخاب می‌شود. وقتی پلاک کامل و معتبر شد، متن کامل آن با `aria-live` خوانده می‌شود.
