کاربر می‌تواند تاریخ را مستقیم تایپ کند (با ارقام فارسی یا انگلیسی، مثل `۱۴۰۳/۵/۱۲`) یا آن را از تقویم انتخاب کند. مقدار کامپوننت یک `Date` استاندارد جاوااسکریپت است، پس سرور شما با تاریخ شمسی سروکار ندارد.

## تاریخ تولد

فهرست ماه و سال برای انتخاب سریع تاریخ‌های دور است. با `name`، مقدار میلادی به شکل `YYYY-MM-DD` در فرم ارسال می‌شود.

<Demo html={false} code={`const [birth, setBirth] = useState<Date | null>(null);

<DatePicker
  label="تاریخ تولد"
  name="birth"
  max={new Date()}
  yearRange={[1300, 1405]}
  onChange={setBirth}
/>`}>
  <BirthDateDemo client:only="react" />
</Demo>

## محدود کردن روزها

با `min`، `max` و `isDateDisabled` روزهای غیرمجاز را مشخص کنید؛ مثلاً برای رزرو نوبت.

<Demo html={false} code={`<DatePicker
  label="تاریخ نوبت"
  min={new Date()}
  isDateDisabled={(date) => date.getDay() === 5} // جمعه
/>`}>
  <AppointmentDemo client:only="react" />
</Demo>

## تقویم مستقل

`Calendar` همان تقویم بدون فیلد است؛ برای صفحه‌های رزرو یا داشبورد.

<Demo html={false} code={`const [date, setDate] = useState<Date | null>(new Date());

<Calendar value={date} onChange={setDate} />`}>
  <InlineCalendarDemo client:only="react" />
</Demo>

| <kbd>Shift</kbd> + <kbd>PageUp</kbd> / <kbd>PageDown</kbd> | سال قبل / سال بعد |

## دسترس‌پذیری

- تقویم از الگوی Date Picker در WAI-ARIA پیروی می‌کند: جدول با نقش `grid`، فقط یک روز در ترتیب Tab، و پیمایش با کلیدهای جهت‌دار.
- هر روز با نام کامل خوانده می‌شود («جمعه ۱۲ مرداد ۱۴۰۳»)، امروز با `aria-current="date"` و روز انتخاب‌شده با `aria-selected` مشخص است.
- تغییر ماه با یک ناحیهٔ `aria-live` اعلام می‌شود.
- دکمهٔ تقویم تاریخ فعلی را هم در نام خود دارد، پس کاربر صفحه‌خوان بدون باز کردن تقویم مقدار را می‌شنود.
- تایپ مستقیم همیشه ممکن است؛ کاربرانی که با تقویم راحت نیستند مجبور به استفاده از آن نیستند.

## تبدیل تاریخ

تبدیل شمسی و میلادی با پکیج `@kashi-ui/persian` انجام می‌شود که برای سال‌های ۱۳۰۰ تا ۱۵۰۰، روزبه‌روز با تقویم رسمی ICU تست شده است. [ابزارهای فارسی](/docs/persian/utilities/) را ببینید.

## تعطیلات

با `holidays`، جمعه‌ها و تعطیلات رسمی ثابت (نوروز، ۱۲ و ۱۳ فروردین، ۱۴ و ۱۵ خرداد، ۲۲ بهمن و ۲۹ اسفند) قرمز نمایش داده می‌شوند و نامشان برای صفحه‌خوان خوانده می‌شود. تعطیلات قمری هر سال با رؤیت ماه جابه‌جا می‌شوند، پس آن‌ها را از تقویم رسمی همان سال بدهید:

<Demo html={false} code={`import { getIranHoliday } from "@kashi-ui/persian";

<Calendar holidays /> // فقط جمعه‌ها و تعطیلات ثابت

<Calendar holidays={(d) => getIranHoliday(d, { extra: { "2026-03-20": "عید فطر" } })} />`}>
  <HolidayDemo client:only="react" />
</Demo>
