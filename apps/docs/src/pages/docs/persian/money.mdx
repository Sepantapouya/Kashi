در محصولات ایرانی مبلغ معمولاً در پایگاه داده به ریال است و به کاربر به تومان نشان داده می‌شود. با `from="rial"` تبدیل خودکار انجام می‌شود. حالت `compact` برای کارت‌ها و جدول‌ها مناسب است و برای اعداد بسیار بزرگ «همت» (هزار میلیارد تومان) را به کار می‌برد.

```ts
import { formatMoney } from "@kashi-ui/persian";
formatMoney(1250000);                    // "۱٬۲۵۰٬۰۰۰ تومان"
formatMoney(1250000, { compact: true }); // "۱٫۲۵ میلیون تومان"
formatMoney(5000, { unit: "rial" });     // "۵۰٬۰۰۰ ریال"
```

## دسترس‌پذیری

عنصر `<data>` مقدار عددی خام را در `value` نگه می‌دارد. صفحه‌خوان به جای ارقام جداشده، مبلغ را به حروف می‌خواند («یک میلیون و دویست و پنجاه هزار تومان»). رنگ مثبت و منفی همیشه همراه علامت + و − است.
