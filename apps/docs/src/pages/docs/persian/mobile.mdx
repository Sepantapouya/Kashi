## نمونه

شماره را به هر شکلی بنویسید یا بچسبانید: `09123456789`، `+98 912 345 6789` یا `00989123456789`.

## رفتار

- **یکدست‌سازی:** `+98`، `0098`، `98` و شمارهٔ بدون صفر اول (`912…`) به شکل استاندارد `09xxxxxxxxx` درمی‌آیند.
- **اپراتور:** همراه اول، ایرانسل و رایتل از روی پیش‌شماره تشخیص داده می‌شوند. به دلیل امکان ترابرد شماره، اپراتور فقط برای راهنمایی است.
- **صفحه‌کلید:** در گوشی صفحه‌کلید تلفن باز می‌شود و مرورگر می‌تواند شمارهٔ ذخیره‌شده را پیشنهاد دهد.

## بدون React

```ts
import { normalizeMobile, isValidMobile, getMobileOperator, formatMobile } from "@kashi-ui/persian";

normalizeMobile("+98 912 345 6789"); // "09123456789"
getMobileOperator("0935")?.name;     // "ایرانسل"
formatMobile("09123456789");         // "0912 345 6789"
```
