## چرا یک input؟

بیشتر پیاده‌سازی‌های OTP شش فیلد جدا دارند که چسباندن، پاک کردن و صفحه‌خوان را خراب می‌کند. کاشی **یک input واقعی** زیر خانه‌های نمایشی دارد، پس:

- **پر شدن خودکار:** با `autocomplete="one-time-code"`، iOS و Android کد پیامک دریافتی را بالای صفحه‌کلید پیشنهاد می‌دهند.
- **چسباندن:** «۱۲۳ ۴۵۶» یا «123-456» هم درست خوانده می‌شود؛ ارقام فارسی و فاصله‌ها پذیرفته می‌شوند.
- **صفحه‌خوان:** یک فیلد با یک برچسب می‌خواند، نه شش فیلد بی‌نام.
- **پاک کردن و جابه‌جایی:** <kbd>Backspace</kbd>، کلیدهای جهت‌دار و انتخاب متن همان رفتار عادی را دارند.
