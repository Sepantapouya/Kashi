به جای به خاطر سپردن نام یازده کامپوننت، یک فیلد با `kind` بسازید. هر نوع برچسب، قالب، اعتبارسنجی و پیام خطای فارسی خودش را دارد. ویژگی‌های دیگر همان کامپوننت تخصصی است و TypeScript بر اساس `kind` آن‌ها را پیشنهاد می‌دهد. مثلاً `showBank` فقط برای `card` و `iban` مجاز است.

| kind | داده | کامپوننت تخصصی |
|---|---|---|
| `text` | متن با پیشنهاد اصلاح زبان صفحه‌کلید | [KeyboardFixInput](#text) |
| `national-id` | کد ملی | [NationalIdInput](#national-id) |
| `legal-id` | شناسهٔ ملی شرکت | [LegalIdInput](#legal-id) |
| `mobile` | موبایل با اپراتور | [MobileInput](#mobile) |
| `landline` | تلفن ثابت با استان | [LandlineInput](#landline) |
| `card` | شمارهٔ کارت با بانک | [CardNumberInput](#card) |
| `iban` | شبا با بانک | [IbanInput](#iban) |
| `price` | مبلغ با حروف | [PriceInput](#price) |
| `postal` | کد پستی | [PostalCodeInput](#postal) |
| `time` | ساعت | [TimeInput](#time) |
| `plate` | پلاک خودرو | [PlateInput](#plate) |

اگر برچسب ندهید، برچسب پیش‌فرض همان نوع («شمارهٔ شبا»، «کد پستی» و…) گذاشته می‌شود. با `aria-label` برچسب دیده نمی‌شود. فهرست برچسب‌ها در `PERSIAN_INPUT_LABELS` است.

## کد ملی

فیلد کد ملی با اعتبارسنجی رقم کنترل؛ ارقام فارسی و انگلیسی را می‌پذیرد.

```tsx
<PersianInput kind="national-id" />   // یا مستقیم: <NationalIdInput />
```

یک کد ملی آزمایشی معتبر: `0013542419`. یک رقم آخر را عوض کنید تا خطا را ببینید.

<Demo html={false} code={`<PersianInput kind="national-id"
  label="کد ملی"
  name="nationalId"
  onValueChange={(value, valid) => console.log(value, valid)}
/>`}>
  <NationalIdDemo client:load />
</Demo>

#### رفتار

- **ارقام:** کاربر می‌تواند با صفحه‌کلید فارسی یا انگلیسی تایپ کند. نمایش با ارقام فارسی است (`digits="latin"` برای انگلیسی)، ولی مقدار همیشه با ارقام انگلیسی به شما داده می‌شود.
- **محدودیت:** هر نویسهٔ غیر رقمی حذف می‌شود و بیش از ۱۰ رقم پذیرفته نمی‌شود. در گوشی، صفحه‌کلید عددی باز می‌شود.
- **اعتبارسنجی:** رقم دهم با الگوریتم رسمی رقم کنترل بررسی می‌شود. پیام خطا فقط پس از خروج از فیلد یا کامل شدن ۱۰ رقم نمایش داده می‌شود، نه هنگام تایپ.
- **فرم:** با `name`، مقدار با ارقام انگلیسی در یک فیلد مخفی ارسال می‌شود.

> اعتبارسنجی رقم کنترل فقط درستی ساختار کد را نشان می‌دهد، نه وجود آن را. برای احراز هویت، کد را با سرویس رسمی استعلام کنید.

#### بدون React


#### دسترس‌پذیری

- خطا با `aria-invalid` و `aria-describedby` به فیلد متصل است.
- فیلد با `dir="ltr"` است تا ترتیب ارقام هنگام تایپ جابه‌جا نشود.

شماره را به هر شکلی بنویسید یا بچسبانید: `09123456789`، `+98 912 345 6789` یا `00989123456789`.

- **صفحه‌کلید:** در گوشی صفحه‌کلید تلفن باز می‌شود و مرورگر می‌تواند شمارهٔ ذخیره‌شده را پیشنهاد دهد.

## شماره کارت

فیلد شماره کارت بانکی با گروه‌بندی خودکار، تشخیص بانک و اعتبارسنجی Luhn.

```tsx
<PersianInput kind="card" />   // یا مستقیم: <CardNumberInput />
```

شش رقم اول را تایپ کنید، مثلاً `603799` یا `610433`، تا لوگو و نام بانک نمایش داده شوند.

<Demo html={false} code={`<PersianInput kind="card"
  label="شماره کارت"
  name="card"
  onValueChange={(value, valid, bank) => console.log(value, valid, bank)}
/>`}>
  <CardNumberDemo client:load />
</Demo>

#### رفتار

- **گروه‌بندی:** ارقام به‌صورت خودکار در گروه‌های چهارتایی نمایش داده می‌شوند. هنگام ویرایش وسط شماره، مکان‌نما سر جای درستش می‌ماند.
- **چسباندن:** شماره‌ای که با فاصله، خط تیره یا ارقام فارسی کپی شده هم درست خوانده می‌شود.
- **تشخیص بانک:** لوگو و نام بانک از شش رقم اول (BIN) تشخیص داده می‌شوند. لوگوها فقط وقتی بانک شناخته شد بارگذاری می‌شوند و حجم اولیهٔ برنامه را زیاد نمی‌کنند ([لوگوی بانک‌ها](/docs/persian/bank-logos/)). فهرست بانک‌ها ممکن است کامل نباشد؛ از آن فقط برای راهنمایی کاربر استفاده کنید.
- **اعتبارسنجی:** شمارهٔ ۱۶ رقمی با الگوریتم Luhn بررسی می‌شود.
- **تکمیل خودکار:** با `autocomplete="cc-number"`، مرورگر می‌تواند کارت ذخیره‌شده را پیشنهاد دهد.

> این فیلد شماره را فقط در مرورگر قالب‌بندی می‌کند. شمارهٔ کارت داده‌ای حساس است؛ آن را فقط از طریق HTTPS ارسال کنید و بدون نیاز ذخیره نکنید.

## شماره شبا

فیلد شبا (IBAN ایران) با IR خودکار، گروه‌بندی، لوگو و نام بانک و بررسی رقم‌های کنترل.

```tsx
<PersianInput kind="iban" />   // یا مستقیم: <IbanInput />
```

فقط ارقام را تایپ کنید؛ «IR» خودکار اضافه می‌شود. با تایپ ارقام ۳ تا ۵ (کد بانک)، لوگو و نام بانک نمایش داده می‌شوند.

<Demo html={false} code={`<PersianInput kind="iban"
  label="شماره شبا"
  name="iban"
  onValueChange={(iban, valid, bank) => console.log(iban, valid, bank)}
/>`}>
  <IbanDemo client:load />
</Demo>

#### رفتار

- **ورودی آزاد:** شبا با یا بدون «IR»، با فاصله یا بدون آن، و با ارقام فارسی یا انگلیسی پذیرفته می‌شود.
- **اعتبارسنجی:** رقم‌های کنترل با استاندارد ISO 13616 (باقیماندهٔ ۹۷) بررسی می‌شوند؛ هر رقم اشتباه یا جابه‌جایی ارقام مجاور تشخیص داده می‌شود.
- **مقدار:** همیشه به شکل `IR` + ۲۴ رقم بدون فاصله به شما داده می‌شود.
- **ارقام:** شبا معمولاً با ارقام انگلیسی نوشته می‌شود؛ برای ارقام فارسی `digits="fa"` بدهید.

## مبلغ

فیلد مبلغ با جداکنندهٔ هزارگان فارسی، واحد پول و نمایش مبلغ به حروف.

```tsx
<PersianInput kind="price" />   // یا مستقیم: <PriceInput />
```

مبلغ به حروف زیر فیلد نمایش داده می‌شود تا کاربر مطمئن شود صفرها را درست وارد کرده است؛ اشتباهی رایج و پرهزینه در پرداخت‌ها.

<Demo html={false} code={`<PersianInput kind="price"
  label="مبلغ پرداخت"
  name="amount"
  max={500_000_000}
  onValueChange={(amount) => console.log(amount)}
/>`}>
  <PriceDemo client:load />
</Demo>

#### رفتار

- **قالب‌بندی:** جداکنندهٔ هزارگان فارسی (`٬`) هنگام تایپ اضافه می‌شود و مکان‌نما سر جایش می‌ماند.
- **به حروف:** «یک میلیون و دویست و پنجاه هزار تومان». با `showWords={false}` خاموش می‌شود.
- **واحد:** پیش‌فرض «تومان»؛ با `unit="ریال"` یا هر متن دیگری عوض می‌شود.
- **مقدار:** عدد (`number`) یا `null` برای فیلد خالی. صفرهای ابتدایی حذف می‌شوند. تا ۱۵ رقم.
- **محدوده:** با `min` و `max`، پس از خروج از فیلد پیام خطا نمایش داده می‌شود.

## اصلاح زبان صفحه‌کلید

اگر کاربر فارسی را با صفحه‌کلید انگلیسی تایپ کند، شکل درست را پیشنهاد می‌دهد: sghl ← سلام.

```tsx
<PersianInput kind="text" />   // یا مستقیم: <KeyboardFixInput />
```

<Demo html={false} code={`<PersianInput kind="text" label="جستجو" value={query} onValueChange={setQuery} />`}>
  <KeyboardFixDemo client:load />
</Demo>

کاربر فارسی‌زبان زیاد پیش می‌آید که فراموش کند زبان صفحه‌کلید را عوض کند و «سلام» را «sghl» تایپ کند. این فیلد شکل فارسی را زیر فیلد پیشنهاد می‌دهد و با یک کلیک جایگزین می‌کند. برای جستجو بیشترین کاربرد را دارد.

تشخیص به‌صورت پیش‌فرض حدسی است (`suggest="auto"`): کلمه‌های لاتینِ بدون حرف صدادار یا با `;`، `'` و `[` در وسط کلمه مشکوک‌اند. برای پیشنهاد روی هر متن لاتین از `suggest="always"` استفاده کنید. تبدیل بر اساس چیدمان استاندارد صفحه‌کلید فارسی است.

```ts
fixKeyboardLayout("sghl o,fd?");       // "سلام خوبی؟"
fixKeyboardLayout("لخخلمث", "en");    // "google"
looksLikeWrongLayout("sghl");          // true
```
