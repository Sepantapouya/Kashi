## کیبورد

| کلید | عمل |
|---|---|
| <kbd>←</kbd> / <kbd>→</kbd> | ماه بعد / قبل (در RTL) |
| <kbd>↑</kbd> / <kbd>↓</kbd> | سه ماه قبل / بعد |
| <kbd>PageUp</kbd> / <kbd>PageDown</kbd> | سال قبل / بعد |
| <kbd>Home</kbd> / <kbd>End</kbd> | فروردین / اسفند |

## دسترس‌پذیری

هر ماه دکمه‌ای با نام کامل («آبان ۱۴۰۵») و `aria-pressed` است؛ ماه جاری `aria-current="date"` دارد. فقط یک ماه در ترتیب Tab است و سال با `aria-live` اعلام می‌شود.
