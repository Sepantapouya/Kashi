## رفتار

- **ارقام:** کاربر می‌تواند با صفحه‌کلید فارسی یا انگلیسی تایپ کند. نمایش با ارقام فارسی است (`digits="latin"` برای انگلیسی)، ولی مقدار همیشه با ارقام انگلیسی به شما داده می‌شود.
- **محدودیت:** هر نویسهٔ غیر رقمی حذف می‌شود و بیش از ۱۰ رقم پذیرفته نمی‌شود. در گوشی، صفحه‌کلید عددی باز می‌شود.
- **اعتبارسنجی:** رقم دهم با الگوریتم رسمی رقم کنترل بررسی می‌شود. پیام خطا فقط پس از خروج از فیلد یا کامل شدن ۱۰ رقم نمایش داده می‌شود، نه هنگام تایپ.
- **فرم:** با `name`، مقدار با ارقام انگلیسی در یک فیلد مخفی ارسال می‌شود.

> اعتبارسنجی رقم کنترل فقط درستی ساختار کد را نشان می‌دهد، نه وجود آن را. برای احراز هویت، کد را با سرویس رسمی استعلام کنید.

## بدون React

```ts
import { isValidNationalId } from "@kashi-ui/persian";

isValidNationalId("۰۰۱۳۵۴۲۴۱۹"); // true
isValidNationalId("1111111111"); // false
```

## دسترس‌پذیری

- خطا با `aria-invalid` و `aria-describedby` به فیلد متصل است.
- فیلد با `dir="ltr"` است تا ترتیب ارقام هنگام تایپ جابه‌جا نشود.
