کاشی یک دیزاین‌سیستم متن‌باز برای محصولات فارسی است. نام آن از کاشی‌کاری ایرانی گرفته شده: قطعه‌های کوچک و دقیق که کنار هم یک کل یکپارچه می‌سازند.

<Install />

## اصول

- **راست‌به‌چپ از پایه.** هیچ استایلی با `left` و `right` نوشته نشده؛ همه‌چیز با Logical Properties است. صفحه‌ای که با `dir="ltr"` باز شود هم بدون تغییر درست نمایش داده می‌شود.
- **دسترس‌پذیری به‌عنوان شرط انتشار.** هدف استاندارد WCAG 2.2 در سطح AA است. کنتراست رنگ‌ها در هر بیلد به‌صورت خودکار بررسی می‌شود و تست‌های خودکار ویژگی‌های ARIA را کنترل می‌کنند.
- **سفارشی‌سازی بدون جنگ با CSS.** همهٔ استایل‌ها در Cascade Layer قرار دارند؛ CSS شما همیشه اولویت دارد، بدون `!important`.
- **مستقل از فریم‌ورک.** ظاهر یک‌بار در CSS تعریف شده و هر فریم‌ورک لایهٔ نازکی روی آن است.

## پکیج‌ها

| پکیج | کاربرد |
|---|---|
| `@kashi-ui/tokens` | توکن‌های طراحی به‌صورت CSS Variables، JSON و JavaScript، به‌همراه `createTheme()` |
| `@kashi-ui/css` | استایل همهٔ کامپوننت‌ها با کلاس‌های `k-*`، به‌همراه فونت وزیرمتن |
| `@kashi-ui/react` | کامپوننت‌های React با تایپ کامل TypeScript |

## وضعیت پروژه

کاشی در نسخهٔ `0.x` است؛ یعنی API ممکن است پیش از نسخهٔ `1.0` تغییر کند. تغییرات ناسازگار همیشه در یادداشت انتشار ذکر می‌شوند.
