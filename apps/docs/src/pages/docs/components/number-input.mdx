## کیبورد

| کلید | عمل |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | یک گام بیشتر / کمتر |
| <kbd>PageUp</kbd> / <kbd>PageDown</kbd> | ده گام |
| <kbd>Home</kbd> / <kbd>End</kbd> | کمینه / بیشینه |

## دسترس‌پذیری

فیلد `role="spinbutton"` با `aria-valuenow`، `aria-valuemin` و `aria-valuemax` است. دکمه‌های + و − از ترتیب Tab بیرون‌اند (کلیدهای جهت همان کار را می‌کنند) و در مرز محدوده غیرفعال می‌شوند.
