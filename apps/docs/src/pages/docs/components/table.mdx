## دسترس‌پذیری

- جدول واقعی HTML با `<caption>` و سرستون‌های `scope="col"`؛ صفحه‌خوان‌ها می‌توانند بین خانه‌ها پیمایش کنند.
- سرستون مرتب‌شده `aria-sort` دارد و مرتب‌سازی با یک دکمهٔ واقعی انجام می‌شود.
- چک‌باکس هر ردیف نام اختصاصی می‌گیرد (`labels.selectRow`)، مثل «انتخاب تراکنش سارا احمدی».
- ظرف جدول در صفحه‌های باریک اسکرول افقی دارد و با کیبورد (Tab) قابل‌اسکرول است.
