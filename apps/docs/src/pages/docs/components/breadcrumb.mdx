## دسترس‌پذیری

داخل `<nav aria-label="مسیر">` با فهرست `<ol>`؛ صفحهٔ فعلی `aria-current="page"` دارد و لینک نیست. جداکننده‌ها تزئینی‌اند و در راست‌به‌چپ آینه می‌شوند.
