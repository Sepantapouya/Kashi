## مسیر بلند

با `maxItems` وسط مسیر به «…» جمع می‌شود؛ با زدن آن، مسیر کامل باز می‌شود. نام‌های بلند هم کوتاه می‌شوند و متن کامل در `title` است.

<Demo html={false} code={`<Breadcrumb maxItems={3} items={[
  { label: "خانه", href: "/", icon: <HomeIcon />, hideLabel: true },
  { label: "پروژه‌ها", href: "/projects" },
  { label: "فروشگاه آنلاین", href: "/projects/shop" },
  { label: "تنظیمات", href: "/projects/shop/settings" },
  { label: "امنیت و ورود دو مرحله‌ای" },
]} />`}>
  <BreadcrumbDemo client:load variant="long" />
</Demo>

## متغیرهای CSS

`--k-breadcrumb-max-item` (پیش‌فرض `14rem`): بیشترین عرض هر مورد پیش از کوتاه شدن.

## دسترس‌پذیری

داخل `<nav aria-label="مسیر">` با فهرست `<ol>`؛ صفحهٔ فعلی `aria-current="page"` دارد و لینک نیست. جداکننده‌ها تزئینی‌اند و در راست‌به‌چپ آینه می‌شوند. «…» یک دکمهٔ واقعی با نام «نمایش مسیر کامل» است.
