## دسترس‌پذیری

فهرست `<ol>` با نام «مراحل»؛ مرحلهٔ فعلی `aria-current="step"` دارد و صفحه‌خوان وضعیت هر مرحله را می‌خواند («ارسال، مرحلهٔ فعلی»، «سبد خرید، انجام شده»). وضعیت فقط با رنگ نمایش داده نمی‌شود: مراحل انجام‌شده تیک دارند.
