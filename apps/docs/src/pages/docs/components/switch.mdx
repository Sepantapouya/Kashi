## سوییچ یا چک‌باکس؟

- **سوییچ:** تغییر فوراً اعمال می‌شود، مثل روشن کردن اعلان‌ها.
- **چک‌باکس:** انتخاب پس از ارسال فرم اعمال می‌شود، مثل پذیرفتن قوانین.

## دسترس‌پذیری

- روی `<input type="checkbox" role="switch">` ساخته شده؛ صفحه‌خوان آن را «سوییچ، روشن» یا «خاموش» اعلام می‌کند.
- مسیر خاموش کنتراست حداقل ۳ به ۱ با پس‌زمینه دارد.
