همان گزینه‌ها و جستجوی `Combobox` را دارد (یکدست‌سازی «ي» و «ی»، توضیح و آیکون). انتخاب‌ها به‌شکل برچسب داخل فیلد نمایش داده می‌شوند و با رسیدن به `max`، بقیهٔ گزینه‌ها غیرفعال می‌شوند. برای وارد کردن مقدار آزاد، که در فهرست نیست، `TagInput` مناسب‌تر است.

## کیبورد

| کلید | عمل |
|---|---|
| <kbd>↓</kbd> / <kbd>↑</kbd> | گزینهٔ بعد / قبل |
| <kbd>Enter</kbd> | انتخاب یا لغو انتخاب گزینهٔ فعال |
| <kbd>Backspace</kbd> در فیلد خالی | حذف آخرین برچسب |
| <kbd>Esc</kbd> | بستن فهرست |

## دسترس‌پذیری

الگوی Combobox با `aria-multiselectable`؛ هر گزینه `aria-selected` دارد و تعداد انتخاب‌ها به فیلد وصل است («۲ مورد انتخاب شده»). افزودن و حذف با `aria-live` اعلام می‌شود.
