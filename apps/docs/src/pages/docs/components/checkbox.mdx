## دسترس‌پذیری

- روی `<input type="checkbox">` بومی ساخته شده؛ کلید Space، فرم‌ها و صفحه‌خوان‌ها بدون کد اضافه کار می‌کنند.
- در حالت کنتراست بالای ویندوز، ظاهر بومی سیستم نمایش داده می‌شود.
- برای گروه چک‌باکس‌ها از `<fieldset>` و `<legend>` استفاده کنید.
