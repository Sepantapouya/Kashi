## دسترس‌پذیری

اسکلت تزئینی است (`aria-hidden`). روی ظرف بارگذاری `aria-busy="true"` و یک `aria-label` بگذارید تا صفحه‌خوان بداند محتوا در راه است. با `prefers-reduced-motion` درخشش متوقف می‌شود.
