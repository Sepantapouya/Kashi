## پاسخ زندهٔ مدل

هر بار که تکهٔ تازه‌ای از پاسخ می‌رسد، `text` را بلندتر کنید و تا پایان پاسخ `streaming` را `true` نگه دارید. فقط کلمه‌های تازه نرم ظاهر می‌شوند؛ کلمه‌هایی که قبلاً دیده شده‌اند دوباره انیمیشن نمی‌گیرند.

<Demo html={false} code={`const [text, setText] = useState("");
const [streaming, setStreaming] = useState(true);

for await (const chunk of stream) setText((t) => t + chunk);
setStreaming(false);

<StreamingText text={text} streaming={streaming} />`}>
  <StreamingLiveDemo client:only="react" />
</Demo>

## پاسخی که یک‌جا رسیده

اگر کل پاسخ یک‌جا رسیده ولی می‌خواهید حس نوشتن داشته باشد، `speed` (کلمه در ثانیه) بدهید. پایان نمایش با `onDone` خبر داده می‌شود.

<Demo html={false} code={`<StreamingText text={answer} speed={14} onDone={() => setDone(true)} />`}>
  <StreamingDemo client:only="react" />
</Demo>

## دسترس‌پذیری

- تا پایان نوشتن، متن `aria-busy` است و صفحه‌خوان کلمه‌به‌کلمه نمی‌خواندش؛ پایان پاسخ یک بار اعلام می‌شود («پاسخ کامل شد»).
- نیم‌فاصله جزو کلمه است، پس «می‌شود» دو تکه نمی‌شود.
- با «کاهش حرکت»، متن بی‌انیمیشن و یک‌جا نمایش داده می‌شود و نشانگر چشمک نمی‌زند.
