## مدل‌ها

چهار انتخاب که با هم ترکیب می‌شوند: نشان صفحهٔ فعلی با `variant` (خط یا قرص)، `centered` برای پیوندهای وسط نوار، `floating` برای نوار جدا از لبه‌ها با گوشهٔ گرد، و `transparent` برای نوار بی‌رنگ روی هیرو که با اسکرول پس‌زمینه می‌گیرد.

<Demo html={false} align="start" code={`<Navbar variant="pill" … />
<Navbar centered variant="pill" … />
<Navbar floating variant="pill" … />
<Navbar transparent … />   // روی تصویر یا هیرو`}>
  <NavbarVariantsDemo client:load />
</Demo>

- **پیش‌فرض** برای سایت محتوایی و مستندات؛ آرام‌ترین مدل.
- **قرص** برای اپ و فروشگاه؛ صفحهٔ فعلی پررنگ‌تر دیده می‌شود.
- **وسط‌چین** وقتی لوگو و دکمه‌ها کم‌اند و پیوندها اصل ماجرا هستند، مثل صفحهٔ معرفی محصول.
- **شناور** برای صفحهٔ فرود؛ با اسکرول جدا از محتوا می‌ماند و سایه‌اش بیشتر می‌شود.
- **شفاف** فقط روی تصویر یا هیروی تیره؛ رنگ متن لوگو را خودتان با پس‌زمینه هماهنگ کنید.

## در گوشی

زیر عرض `collapseBelow` پیوندها در یک [کشو](/docs/components/drawer/) جمع می‌شوند و دکمهٔ منو جایشان را می‌گیرد. `menuFooter` پایین همان کشو است، مثلاً دکمهٔ ثبت‌نام.

## با Next.js و روترها

پیوندها پیش‌فرض `<a>` هستند. برای پیمایش بدون بارگذاری دوباره، کامپوننت پیوند روتر را بدهید:

```tsx
import Link from "next/link";

<Navbar linkAs={Link} links={links} brand={…} />
```

`current` را از مسیر فعلی بسازید، مثلاً `current: pathname.startsWith(href)`.

## دسترس‌پذیری

- پیوندها داخل `<nav>` با نام «ناوبری اصلی» هستند و صفحهٔ فعلی `aria-current="page"` دارد.
- دکمهٔ منو `aria-expanded` و `aria-haspopup="dialog"` دارد و منوی گوشی همان کشوی دسترس‌پذیر است.
- اگر صفحه پیوند «پرش به محتوا» دارد، آن را پیش از نوار بگذارید.
