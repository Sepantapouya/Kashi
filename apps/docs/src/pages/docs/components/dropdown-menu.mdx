## کیبورد

| کلید | عمل |
|---|---|
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>↓</kbd> | باز کردن و رفتن به اولین گزینه |
| <kbd>↑</kbd> روی دکمه | باز کردن و رفتن به آخرین گزینه |
| <kbd>↑</kbd> / <kbd>↓</kbd> | گزینهٔ قبل / بعد (گزینه‌های غیرفعال رد می‌شوند) |
| <kbd>Home</kbd> / <kbd>End</kbd> | اولین / آخرین گزینه |
| حرف | پرش به گزینه‌ای که با آن حرف شروع می‌شود |
| <kbd>Esc</kbd> | بستن و برگشت به دکمه |
| <kbd>Tab</kbd> | بستن و رفتن به عنصر بعدی صفحه |

## گزینه‌های تیک‌دار

برای تنظیماتی مثل نمایش ستون‌ها؛ منو پس از انتخاب باز می‌ماند تا چند گزینه پشت سر هم عوض شوند.

<Demo html={false} code={`<MenuItem checked={cols.date} onSelect={() => toggle("date")}>تاریخ</MenuItem>`}>
  <MenuCheckDemo client:load />
</Demo>

`checked` نقش گزینه را `menuitemcheckbox` با `aria-checked` می‌کند. متغیرهای CSS: `--k-menu-min-width`، `--k-menu-radius`، `--k-menu-item-height`، `--k-menu-bg`.

## دسترس‌پذیری

- دکمه `aria-haspopup="menu"` و `aria-expanded` دارد؛ منو `role="menu"` با گزینه‌های `menuitem`.
- فوکوس داخل منو با کلیدهای جهت‌دار جابه‌جا می‌شود، نه Tab؛ پس از انتخاب یا Esc، فوکوس به دکمه برمی‌گردد.
- منو برای **عمل‌ها** است. برای انتخاب یک مقدار در فرم از [انتخاب از فهرست](/docs/components/select/) استفاده کنید.
