## نمونه

کد در صفحهٔ راست‌به‌چپ هم چپ‌به‌راست می‌ماند، ولی توضیح فارسی داخلش درست خوانده می‌شود. رنگ‌آمیزی سبک و بی‌وابستگی است و از رنگ‌های نمودار کاشی استفاده می‌کند، پس در تم تیره و کنتراست بالا هم درست است.

<Demo align="stretch" html={false} code={`<CodeBlock
  language="tsx"
  filename="App.tsx"
  lineNumbers
  highlightLines={[4]}
  code={source}
/>`}>
  <CodeBlockDemo client:only="react" />
</Demo>

دکمهٔ شکستن خط بین اسکرول افقی و شکستن خط‌های بلند جابه‌جا می‌کند. برای رنگ‌آمیزی کامل‌تر (مثلاً با Shiki)، خروجی را خودتان بسازید و فقط از کلاس‌های `k-code` استفاده کنید.

تابع `highlightCode(code, language)` هم جدا در دسترس است.

## دسترس‌پذیری

- ناحیهٔ کد با Tab فوکوس می‌گیرد تا کاربر صفحه‌کلید بتواند کد بلند را افقی اسکرول کند.
- «کپی شد» برای صفحه‌خوان هم اعلام می‌شود؛ دکمهٔ شکستن خط `aria-pressed` دارد.
- شمارهٔ خط‌ها از صفحه‌خوان و از متن کپی‌شده بیرون است.
