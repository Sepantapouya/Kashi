## صفحه‌کلید و دسترس‌پذیری

از نسخهٔ ۲، فهرست با ظاهر کاشی باز می‌شود و نقش‌های ARIA الگوی combobox و listbox را دارد:

- <kbd>↓</kbd> یا <kbd>Enter</kbd> یا <kbd>Space</kbd> فهرست را باز می‌کند؛ فلش‌ها، <kbd>Home</kbd> و <kbd>End</kbd> بین گزینه‌ها جابه‌جا می‌شوند و <kbd>Escape</kbd> می‌بندد.
- تایپ حرف اول یک گزینه مستقیم به آن می‌پرد؛ حتی وقتی فهرست بسته است.
- اگر پایین فیلد جا نباشد، فهرست بالای آن باز می‌شود.

زیر آن یک `<select>` بومیِ پنهان هست، پس `name`، `required`، `onChange` و `ref` دقیقاً مثل قبل کار می‌کنند و فرم بدون کد اضافه ارسال می‌شود.

## فهرست بومی

برای فهرست‌های خیلی بلند، یا وقتی انتخاب‌گر سیستم‌عامل گوشی را ترجیح می‌دهید، `native` بدهید تا همان `<select>` مرورگر با ظاهر کاشی نمایش داده شود. در HTML ساده (بدون React) هم کلاس `k-select` همین فهرست بومی را می‌سازد.

```tsx
<Select native label="کشور" options={countries} />
```
