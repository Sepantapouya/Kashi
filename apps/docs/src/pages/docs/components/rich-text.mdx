## نمونه

Shift+Space نیم‌فاصله می‌گذارد. دکمهٔ جهت، بند فعلی را چپ‌به‌راست یا راست‌به‌چپ می‌کند تا جملهٔ انگلیسی وسط متن فارسی درست بنشیند. Ctrl+B و Ctrl+I و Ctrl+K (پیوند) هم کار می‌کنند. نوار ابزار یک توقف Tab است و با کلیدهای جهت بین دکمه‌ها حرکت می‌کنید.

<Demo align="stretch" html={false} code={`<RichTextEditor
  label="توضیحات محصول"
  defaultValue={html}
  onChange={(html, text) => save(html)}
  hint="متن چسبانده‌شده پاک‌سازی می‌شود."
  name="description"
/>`}>
  <RichTextDemo client:only="react" />
</Demo>

خروجی HTML پاک‌شده است: فقط بند، عنوان دو و سه، پررنگ، کج، زیرخط، خط‌خورده، فهرست، نقل‌قول، کد و پیوند `http`، `https` یا `mailto` می‌ماند و هر ویژگی دیگری (مثل `style` یا `onclick`) حذف می‌شود. متنی که از Word یا سایت دیگری چسبانده شود هم همین‌طور پاک می‌شود. HTML را در سرور هم دوباره پاک کنید؛ تابع `sanitizeRichText` برای همین در دسترس است.

## دسترس‌پذیری

- ناحیهٔ نوشتن `role="textbox"` با `aria-multiline` است و برچسب و راهنما به آن وصل‌اند.
- نوار ابزار `role="toolbar"` با فوکوس گردشی است؛ دکمه‌های قالب `aria-pressed` دارند و همراه مکان‌نما به‌روز می‌شوند.
- میان‌بر نیم‌فاصله در متن راهنما هم برای صفحه‌خوان نوشته شده است.
