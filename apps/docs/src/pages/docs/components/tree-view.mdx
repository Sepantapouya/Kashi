## کیبورد

| کلید | عمل |
|---|---|
| <kbd>↓</kbd> / <kbd>↑</kbd> | ردیف بعد / قبل |
| <kbd>←</kbd> (در RTL) | باز کردن، یا رفتن به اولین زیرشاخه |
| <kbd>→</kbd> (در RTL) | بستن، یا رفتن به والد |
| <kbd>Home</kbd> / <kbd>End</kbd> | اولین / آخرین ردیف |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | انتخاب |

در صفحه‌های چپ‌به‌راست، جهت ← و → برعکس است.

## دسترس‌پذیری

الگوی Tree در WAI-ARIA با `role="tree"`، `treeitem` و `group`؛ هر گره `aria-level` و `aria-expanded` دارد و فقط یک گره در ترتیب Tab است (roving tabindex). زیرشاخه‌های بسته رندر نمی‌شوند.
