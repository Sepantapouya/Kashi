## دسترس‌پذیری

هر نمونه یک چک‌باکس (یا با `single` رادیو) بومی با برچسب متنی است، پس رنگ تنها راه شناختن آن نیست. انتخاب با تیک و حلقهٔ برند هم نشان داده می‌شود و صفحه‌خوان «انتخاب شده» را می‌خواند. همهٔ نمونه‌ها یک حاشیهٔ نازک دارند تا رنگ‌های روشن مثل سفید روی زمینهٔ روشن گم نشوند.
