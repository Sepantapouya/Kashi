## نمونه

زنگ شمار اعلان‌های خوانده‌نشده را دارد و با رسیدن اعلان تازه یک بار تکان می‌خورد. کلیک روی اعلان آن را خوانده می‌کند؛ نقطهٔ کنار هر اعلان هم همین کار را بدون باز کردنش انجام می‌دهد.

<Demo html={false} code={`const [items, setItems] = useState(notifications);

<NotificationCenter
  items={items}
  onRead={(id) => setItems((l) => l.map((x) => (x.id === id ? { ...x, read: true } : x)))}
  onReadAll={() => setItems((l) => l.map((x) => ({ ...x, read: true })))}
  onSettings={openSettings}
  viewAllHref="/notifications"
/>`}>
  <NotificationCenterDemo client:only="react" />
</Demo>

## دسترس‌پذیری

- نام دکمهٔ زنگ تعداد خوانده‌نشده‌ها را می‌گوید («اعلان‌ها، ۲ خوانده‌نشده»)؛ عدد روی زنگ برای صفحه‌خوان تکرار نمی‌شود.
- پاپ‌اور `role="dialog"` است، با Escape بسته می‌شود و فوکوس به زنگ برمی‌گردد.
- هر اعلان یک دکمه یا پیوند است و زمانش در عنصر `<time>` با تاریخ دقیق است. گروه‌ها عنوان دارند.
- اعلان خوانده‌نشده فقط با رنگ نشان داده نمی‌شود؛ دکمهٔ «علامت خوانده‌شده» کنارش است.
