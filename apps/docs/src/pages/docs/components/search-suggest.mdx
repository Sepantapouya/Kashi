## نمونه

روی فیلد بزنید: با فیلد خالی، جستجوهای اخیر (با «پاک کردن») و جستجوهای پرطرفدار با آیکون روند دیده می‌شوند. با تایپ، پیشنهادها با قسمت پیداشدهٔ پررنگ می‌آیند.

## ذخیرهٔ خودکار جستجوهای اخیر

اگر جستجوهای اخیر را خودتان نگه نمی‌دارید، `storageKey` بدهید. هر جستجو (حداکثر ۸ مورد) در مرورگر کاربر ذخیره می‌شود و «پاک کردن» همه را حذف می‌کند.

```tsx
<SearchSuggest storageKey="shop-recent" popular={popular} onSearch={search} />
```

## پیشنهاد از سرور

به‌جای آرایه، تابعی بدهید که برای هر عبارت فهرست برگرداند؛ مثلاً از نتیجهٔ آخرین درخواست. جستجوی آرایه‌ای «ی» و «ک» عربی و نیم‌فاصله را یکسان می‌بیند.

```tsx
<SearchSuggest suggestions={(q) => results[q] ?? []} onChange={fetchSuggestions} />
```

## دسترس‌پذیری

فیلد نقش `combobox` دارد و پیشنهادها `listbox` هستند؛ با <kbd>↓</kbd> و <kbd>↑</kbd> بین پیشنهادها جابه‌جا می‌شوید، <kbd>Enter</kbd> جستجو می‌کند و <kbd>Escape</kbd> پنل را می‌بندد (و بار دوم متن را پاک می‌کند). جستجوهای اخیر و پرطرفدار دکمه‌اند و با <kbd>Tab</kbd> در دسترس‌اند. فرم نقش `search` دارد تا صفحه‌خوان آن را به‌عنوان بخش جستجو بشناسد.
