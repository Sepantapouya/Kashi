## کیبورد

| کلید | عمل |
|---|---|
| <kbd>Enter</kbd> روی متن | شروع ویرایش |
| <kbd>Enter</kbd> در فیلد | ثبت |
| <kbd>Esc</kbd> | انصراف و برگشت به متن |

## دسترس‌پذیری

حالت نمایش یک دکمه با نام کامل است («نام پروژه: بازطراحی فروشگاه، ویرایش»). پس از ثبت یا انصراف، فوکوس به همان دکمه برمی‌گردد.
