## نمونه

Enter پیام را می‌فرستد و Shift+Enter خط تازه می‌سازد. وقتی با صفحه‌کلید IME (مثلاً ژاپنی یا چینی) در حال ترکیب حروف هستید، Enter ارسال نمی‌کند. کادر تا `maxRows` ردیف بلند می‌شود و بعد اسکرول می‌خورد. تصویری که در کادر بچسبانید هم پیوست می‌شود.

<Demo html={false} code={`const [streaming, setStreaming] = useState(false);

<ChatComposer
  attach="image/*,.pdf"
  maxSize={5 * 1024 * 1024}
  showHint
  streaming={streaming}
  onStop={() => controller.abort()}
  onSend={async ({ text, files }) => {
    setStreaming(true);
    await ask(text, files);
    setStreaming(false);
  }}
/>`}>
  <ComposerDemo client:only="react" />
</Demo>

تا وقتی پاسخ در حال نوشتن است (`streaming`)، دکمهٔ ارسال به «توقف» تبدیل می‌شود. فایل بزرگ‌تر از `maxSize` یا بیشتر از `maxFiles` با پیام خطای فارسی رد می‌شود.

## دسترس‌پذیری

- کادر `<textarea>` بومی با نام دسترس‌پذیر است و راهنمای کلیدها با `aria-describedby` به آن وصل است.
- دکمه‌های فقط‌آیکون (پیوست، ارسال، توقف، حذف پیوست) نام فارسی دارند؛ دکمهٔ حذف نام فایل را هم می‌گوید.
- خطای پیوست با `role="alert"` همان لحظه خوانده می‌شود.
- جهت متن خودکار است: پیام انگلیسی چپ‌چین می‌شود.
