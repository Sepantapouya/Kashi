برای جستجوی سمت سرور، `onInputChange` را بگیرید، `options` را از پاسخ سرور بسازید، `loading` را در زمان درخواست روشن کنید و `filter={() => true}` بدهید.

ابزارهای `defaultFilter`، `searchText` و `highlight` هم صادر شده‌اند تا در جستجوهای خودتان استفاده کنید.

## کیبورد

| کلید | عمل |
|---|---|
| <kbd>↓</kbd> / <kbd>↑</kbd> | باز کردن فهرست و رفتن به گزینهٔ بعد / قبل |
| <kbd>Enter</kbd> | انتخاب گزینهٔ فعال |
| <kbd>Esc</kbd> | بستن فهرست؛ اگر بسته است، پاک کردن مقدار |
| <kbd>Home</kbd> / <kbd>End</kbd> | اولین / آخرین گزینه (وقتی فهرست باز است) |

## دسترس‌پذیری

الگوی Combobox در WAI-ARIA با `aria-activedescendant`: فوکوس همیشه در فیلد می‌ماند و صفحه‌خوان گزینهٔ فعال را می‌خواند. تعداد نتیجه‌ها پس از هر تایپ با یک ناحیهٔ `aria-live` اعلام می‌شود («۳ نتیجه») و گزینه‌های غیرفعال `aria-disabled` دارند.
