## نمونه

<TagInput label="مهارت‌ها" value={tags} onChange={setTags} max={5}
  hint="با Enter یا ویرگول جدا کنید؛ حداکثر ۵ مورد." />`}>
  <TagInputDemo client:load />

با <kbd>Enter</kbd>، ویرگول انگلیسی و ویرگول فارسی «،» برچسب ساخته می‌شود؛ متن چسبانده‌شده هم جدا می‌شود. <kbd>Backspace</kbd> در فیلد خالی آخرین برچسب را حذف می‌کند.

## دسترس‌پذیری

هر برچسب دکمهٔ حذف با نام «حذف React» دارد. افزودن، حذف و خطاها (تکراری، بیش از حد مجاز) با `aria-live` اعلام می‌شوند و پیام خطا به فیلد وصل است.
