## نمونه

روی هر تصویر بزنید. در نمایش تمام‌صفحه کلیدهای جهت (در راست‌به‌چپ، چپ یعنی بعدی)، Home و End، کشیدن انگشت و نوار پایین کار می‌کنند. با کلیک روی تصویر همان نقطه بزرگ می‌شود و Escape اول بزرگ‌نمایی و بعد خود پنجره را می‌بندد.

## تعداد محدود

با `max` فقط چند تصویر اول نشان داده می‌شود و روی آخری «+۳» می‌آید؛ همهٔ تصویرها در نمایش تمام‌صفحه هستند. `loop` از آخر به اول برمی‌گرداند.

</Demo>

## فقط نمایش تمام‌صفحه

اگر شبکهٔ تصویرها را خودتان می‌سازید (مثلاً صفحهٔ محصول)، `Lightbox` را جدا استفاده کنید:

```tsx
const [open, setOpen] = useState<number | null>(null);

<button onClick={() => setOpen(0)}><img src={photos[0].thumb} alt="" /></button>
<Lightbox images={photos} index={open} onIndexChange={setOpen} />
```

## دسترس‌پذیری

- نمایش تمام‌صفحه روی `<dialog>` بومی است: فوکوس داخلش می‌ماند و پس از بستن به همان تصویر کوچک برمی‌گردد.
- هر تصویر کوچک دکمه‌ای با نام «بزرگ کردن …» است؛ `alt` را حتماً بدهید.
- شمارندهٔ «۲ از ۶» با `aria-live` اعلام می‌شود و دکمه‌های قبلی و بعدی و بزرگ‌نمایی نام دارند.
- تصویرهای کنار تصویر فعلی از قبل بارگذاری می‌شوند تا جابه‌جایی بی‌مکث باشد.
