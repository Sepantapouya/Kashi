## دسترس‌پذیری

الگوی Carousel در WAI-ARIA: ظرف با `aria-roledescription="اسلایدر"` و هر اسلاید با نام «۲ از ۵». ریل اسلایدها فوکوس‌پذیر است و ←→ بین آن‌ها حرکت می‌کند؛ اسلاید فعال با `aria-live` اعلام می‌شود.
