## Variants

Use only one `primary` button per section of the page. An important second action (such as "Contact sales" next to "Get started") takes `outline`, and every other action takes `secondary` or `tertiary`.

## With an icon

In RTL, `iconStart` sits on the right and `iconEnd` on the left. Mark directional icons such as arrows with `data-k-mirror` so they flip in RTL.

## Shape, size and links

With `href` the button becomes a real link (`<a>`). With `as` you can pass your router's link component, such as `as={Link}` in Next.js.

<Demo example="ButtonExtrasDemo" code={`<Button variant="primary" shape="pill">کاملاً گرد</Button>
<Button shape="square">گوشهٔ کم</Button>
<Button size="xs">خیلی کوچک</Button>
<Button href="/docs" variant="link">دکمهٔ لینکی</Button>
<Button as={Link} href="/pricing">با Link در Next.js</Button>`}>

## Accessibility

- While `loading`, `aria-disabled` is used instead of `disabled` so keyboard focus is not lost, and the text "در حال بارگذاری" (loading) is announced with `role="status"`.
- An `iconOnly` button without `aria-label` warns in development.
- The minimum touch target is 24×24 px, and the focus ring stays visible in Windows high-contrast mode.
- To navigate to another page, use a link (`<a class="k-btn">`), not a button.
