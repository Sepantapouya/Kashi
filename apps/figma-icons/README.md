# Kashi Icons — پلاگین فیگما

پلاگین جدا و سبک برای مرور و خروجی گرفتن از همهٔ آیکون‌های `@kashi-ui/icons`، داخل و بیرون فیگما. (کیت کامل کامپوننت‌ها در `apps/figma-plugin` است.)

- جست‌وجوی فارسی و انگلیسی (نام، عنوان، کلیدواژه و نام دسته)، دسته‌ها در ستون کنار، علاقه‌مندی‌ها و استفادهٔ اخیر
- شش سبک: خطی، توپر، حجمی، دورنگ، شکسته، منحنی؛ رنگ، اندازه (۱۶ تا ۴۸) و ضخامت خط
- افزودن به فیگما با دکمه، دوبار کلیک، Enter در جست‌وجو یا کشیدن روی بوم؛ داخل فریم انتخاب‌شده می‌نشیند
- دانلود SVG و PNG (۱×، ۲×، ۳×)، چند آیکون با هم در ZIP، کپی کد SVG، React و HTML
- انتخاب چندتایی با ⌘/Ctrl و Shift، ⌘A برای همه، `/` برای جست‌وجو، Esc برای پاک کردن
- پوستهٔ روشن و تیره همراه فیگما؛ سه اندازهٔ پنل؛ تنظیمات در `figma.clientStorage` می‌ماند
- بدون دسترسی به شبکه؛ داده، فونت وزیرمتن و موتور سبک‌ها داخل پنل جاسازی شده‌اند

## ساخت و تست

```bash
npm run build -w @kashi-ui/icons
npm run figma-icons:test
```

`build.mjs` سه خروجی می‌سازد: `plugin/` برای Import plugin from manifest، `apps/docs/public/downloads/kashi-icons-figma-plugin.zip` برای دانلود از سایت و `apps/docs/public/icon-exporter.html`، همان پنل به‌صورت صفحهٔ وب. `src/code.js` (بخش sandbox) باید بدون `?.`، `??` و تابع پیکانی بماند.
